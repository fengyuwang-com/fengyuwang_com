## 從一道經濟學題說起

法國數學家古諾 1838 年算過一個模型：n 家企業做產量競爭，均衡價格隨企業數增加趨向邊際成本。1883 年，另一位法國人伯特蘭寫書評開炮——企業明明是定價的，不是定產量的。他證明：只要產品同質、產能無約束、消費者無摩擦選最便宜的，兩家就夠了。任何高於邊際成本的定價，對手只要便宜一丁點就能搶走整個市場。

削價一路打到 P = MC，零經濟利潤。

這就是「伯特蘭悖論」：雙寡頭跑出了完全競爭的結果。140 年來，教科書說它「幾乎不會在現實中發生」，因為三條假設條條不成立——產能總有約束，產品總有差異，博弈從不是一次性的。

直到 Token 出現了。

## Token 為什麼特殊

過去二十年，互聯網商品邊際成本幾乎為零——多一個用戶複製一份數據的成本是 0。按伯特蘭邏輯一路削價，終點是 $0，那就是「免費 + 廣告」。所以沒人用邊際成本定價解釋 SaaS、流媒體、社交。

Token 不一樣。每吐出一個 token 都在實打實燒 GPU、耗電。智譜 2025 上半年算力服務費佔研發開支 71.8%。邊際成本為正且線性不遞減——降價才有底，定價才有錨。

更關鍵的是，Token 市場幾乎滿足了伯特蘭的每一條假設：

- **同質化**：前沿模型在基準上差距收窄到 5% 左右，能力可直接比對
- **價格瞬時可調**：改個 API 價目表就行，比超市換價簽還快
- **切換摩擦極低**：OpenRouter 上換模型就是改一行代碼
- **供給者眾多**：1900+ 個模型、222 家服務商

## 數據驗證了理論

Silicon Data 的 token 支出指數：

| 時間 | 價格（美元／百萬 token） |
|---|---|
| 2024 年初 | ~60 |
| 2026 年 5 月 | 2.04 |
| 2026 年 9 月 | 0.97（首次破 1） |

兩年跌去 98%。這不是融資補貼戰——MoE 架構、MLA 壓縮 KV Cache、推理引擎優化把成本真打下來了。成本性降價，降完趴在新水位上，回不去。

## 兩個逃離悖論的出口

教科書裡對伯特蘭悖論的修正，Token 市場恰好都佔了：

**1. 算力是硬產能約束（埃奇沃思修正）**

GPU 不是一夜之間變多的。產能有限時，純策略均衡可能根本不存在，價格在產能利用率和閒置之間來回震盪——這就是為什麼 2024 年某些模型排隊降價、某些模型供不應求。

**2. 差異化從模型能力轉到上下文工程（Brand & Switching Cost）**

模型本身同質了，但「誰擁有你的代碼庫上下文、誰接入了你的 CI/CD、誰記住了你團隊的編碼風格」——這些是轉換成本。AI Coding Agent 的護城河不在模型，在工作流深度綁定。這是產品差異化，不是價格競爭。

## 所以 Coding Agent 到底有沒有護城河？

回到一個更實際的問題：如果模型 API 在跑伯特蘭，那基於 API 的 Agent 產品有沒有壁壘？

數據層面：代碼在 Git 裡，可導出。對話歷史在本地，可帶走。GDPR 甚至規定必須可攜帶。從「資產鎖定」看，Coding Agent 和微信完全不是一回事——沒有網絡效應，單機工具。

但真正的競爭不在數據層：

- **工作流集成**：Agent 嵌入 CI/CD、Jira、私有代碼規範後，遷移不是帶走代碼，是重寫整套自動化
- **上下文積累**：哪些函數有歷史坑、團隊編碼風格、架構決策的 why——這些餵給新 Agent 要重新學
- **信任校準**：知道它在哪些場景會犯錯、哪些 prompt 能精準觸發——人機磨合需要時間

類比修正：Coding Agent 的護城河不是「微信式關係鏈鎖定」，更像「IDE 式肌肉記憶鎖定」。你用慣了 IntelliJ，即使 VS Code 免費且更好用，你也不一定遷移。

## 殘酷終局推演

- **底層模型層**：伯特蘭價格戰，一路貼邊際成本。活下來的靠 GPU 規模和推理效率，不靠品牌
- **應用層 Agent**：卷集成深度和上下文積累。誰成為開發者「默認操作系統」，誰佔住肌肉記憶生態位
- **最終格局**：可能 2-3 家巨頭活下來，因為只有它們有資本貼 token 價格，同時有工程能力維護複雜集成

如果你相信 AI 能做到「一鍵遷移工作流且遷移得比原來更好」——那所謂護城河會在瞬間消失。但這裡有個悖論：如果 AI 真能做到這點，它本身就成了那個「終極操作系統」，底層 Coding Agent 變成了水電煤。護城河沒有消失，只是向上移動了一層。

## 一句話總結

Token 市場是數字時代第一次、也是最接近教科書伯特蘭悖論的真實案例。它證明了：同質化 + 正邊際成本 + 無摩擦切換 = 價格趨近成本。也證明了：要逃離這個宿命，要麼有產能約束（GPU），要麼有轉換成本（工作流綁定）。兩條路都不容易，所以 AI 公司的毛利率，大概率不會像 SaaS 那樣「躺賺」。
