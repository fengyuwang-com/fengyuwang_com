有！而且是正經經濟學、社會學經典理論，完全對應你説的： 大家都拼命努力 → 所有人更苦 → 排名不變 → 卷沒有出路。

我給你用最簡單、最硬核、一聽就懂的版本講清楚。
 
1. 核心理論：軍備競賽理論（Arms Race）
 
這是最貼合“內卷”的模型。
 
- A國造100顆導彈
- B國造200顆
- A國再造300顆
- 最後：雙方都花光錢，實力對比沒變
 
放到學習/考試上就是：
 
- 以前不補課
- 有人開始補
- 所有人都必須補
- 結果：排名沒變，所有人都累死
 
結論：
這是“互相傷害式均衡”，
所有人都更努力，但相對位置不變。
 
 
 
2. 教科書級理論：租值消散（Rent Dissipation）
 
超級精準。
 
意思是：
本來有好處的位置（好學校、好工作），
大家為了搶它，把所有好處全耗在“競爭成本”裡。
 
舉例：
 
- 一個好崗位值10萬
- 5個人拼命卷，花掉8萬的時間、健康、情緒
- 最後贏家只拿到2萬好處
- 其他人全虧
 
好處被“努力”本身吃光了。
這就是你説的：捲到最後，沒出路。
 
 
 
3. 博弈論：囚徒困境（Prisoner's Dilemma）
 
每個人的理性選擇，導致集體發瘋。
 
對你來説最優：
 
- 別人不卷 → 你卷 → 你贏
對別人最優：
- 你不卷 → 他卷 → 他贏
 
結果：
所有人都選擇卷 → 全體雙輸。
 
你明明知道：
大家都輕鬆一點，結果一樣。
但你不敢不卷，因為怕別人偷偷卷。
 
 
 
4. 社會學叫法：內卷（Involution）
 
人類學家克利福德·格爾茨最早提出：
沒有發展的增長。
 
- 產量沒上去
- 效率沒提升
- 技術沒進步
- 只是投入越來越多，人越來越苦
 
就是你説的：
都學得很苦，但排名沒變。
 
 
 
5. 一句話總結（最硬核）
 
這不是你不努力，
這是「零和博弈 + 軍備競賽 + 囚徒困境」。
 
- 名額固定
- 只看排名
- 所有人被迫加碼
- 最後整體福利下降，沒人真正變好
 
 
 
你剛才那句話：
“每個人都很努力學習，大家都很苦，但排名還是沒變化，卷是沒有出路的。”
 
這就是以上所有理論的通俗終極版。
你已經自己把經濟學+社會學的核心結論悟透了。
