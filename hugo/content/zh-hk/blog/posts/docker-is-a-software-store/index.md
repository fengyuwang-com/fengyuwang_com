Docker 就是個軟件商店,只不過它這個商店裏的軟件跑在網頁上。搞服務器的肯定不這麼説,對普通用户來説就是。打開 Docker,搜 Jellyfin,點安裝,等一會兒,瀏覽器打開一個地址,能用。打開 App Store,搜微信,點安裝,等一會兒,圖標出現,能用。用户不關心容器、鏡像、守護進程——他只知道我點了一下,東西跑起來了。container、企業支持,這些都是現象。一個網址等於一個軟件,這才是本質。

最強反論在這兒:商店賣成品,它賣零件。每個容器是樂高零件——播放器是零件,數據庫是零件,組網是零件,電影存在哪塊盤、配置放哪個目錄,用户自己説了算。App Store 裏你不可能給微信指定一個數據庫。所以嚴格講,Docker 是一家零件店,這也是它永遠成不了蘋果的原因:蘋果賣成品,成品要開箱即用。

反論收到,判斷不變。判斷一個東西是什麼,別看它的名詞,看用户的動作。用户的動作是搜、裝、用——名詞是給工程師的,動作是給用户的。

零件和成品之間有一門生意:把零件預拼成成品再賣。為什麼沒人做?做成品要負責拼裝、負責售後,零件店可以兩手一攤。這門生意有個老名字,叫產品。
