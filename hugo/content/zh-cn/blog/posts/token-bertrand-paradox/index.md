## 从一道经济学题说起

法国数学家古诺 1838 年算过一个模型：n 家企业做产量竞争，均衡价格随企业数增加趋向边际成本。1883 年，另一位法国人伯特兰写书评开炮——企业明明是定价的，不是定产量的。他证明：只要产品同质、产能无约束、消费者无摩擦选最便宜的，两家就够了。任何高于边际成本的定价，对手只要便宜一丁点就能抢走整个市场。

削价一路打到 P = MC，零经济利润。

这就是"伯特兰悖论"：双寡头跑出了完全竞争的结果。140 年来，教科书说它"几乎不会在现实中发生"，因为三条假设条条不成立——产能总有约束，产品总有差异，博弈从不是一次性的。

直到 Token 出现了。

## Token 为什么特殊

过去二十年，互联网商品边际成本几乎为零——多一个用户复制一份数据的成本是 0。按伯特兰逻辑一路削价，终点是 $0，那就是"免费 + 广告"。所以没人用边际成本定价解释 SaaS、流媒体、社交。

Token 不一样。每吐出一个 token 都在实打实烧 GPU、耗电。智谱 2025 上半年算力服务费占研发开支 71.8%。边际成本为正且线性不递减——降价才有底，定价才有锚。

更关键的是，Token 市场几乎满足了伯特兰的每一条假设：

- **同质化**：前沿模型在基准上差距收窄到 5% 左右，能力可直接比对
- **价格瞬时可调**：改个 API 价目表就行，比超市换价签还快
- **切换摩擦极低**：OpenRouter 上换模型就是改一行代码
- **供给者众多**：1900+ 个模型、222 家服务商

## 数据验证了理论

Silicon Data 的 token 支出指数：

| 时间 | 价格（美元/百万 token） |
|---|---|
| 2024 年初 | ~60 |
| 2026 年 5 月 | 2.04 |
| 2026 年 9 月 | 0.97（首次破 1） |

两年跌去 98%。这不是融资补贴战——MoE 架构、MLA 压缩 KV Cache、推理引擎优化把成本真打下来了。成本性降价，降完趴在新水位上，回不去。

## 两个逃离悖论的出口

教科书里对伯特兰悖论的修正，Token 市场恰好都占了：

**1. 算力是硬产能约束（埃奇沃思修正）**

GPU 不是一夜之间变多的。产能有限时，纯策略均衡可能根本不存在，价格在产能利用率和闲置之间来回震荡——这就是为什么 2024 年某些模型排队降价、某些模型供不应求。

**2. 差异化从模型能力转到上下文工程（Brand & Switching Cost）**

模型本身同质了，但"谁拥有你的代码库上下文、谁接入了你的 CI/CD、谁记住了你团队的编码风格"——这些是转换成本。AI Coding Agent 的护城河不在模型，在工作流深度绑定。这是产品差异化，不是价格竞争。

## 所以 Coding Agent 到底有没有护城河？

回到一个更实际的问题：如果模型 API 在跑伯特兰，那基于 API 的 Agent 产品有没有壁垒？

数据层面：代码在 Git 里，可导出。对话历史在本地，可带走。GDPR 甚至规定必须可携带。从"资产锁定"看，Coding Agent 和微信完全不是一回事——没有网络效应，单机工具。

但真正的竞争不在数据层：

- **工作流集成**：Agent 嵌入 CI/CD、Jira、私有代码规范后，迁移不是带走代码，是重写整套自动化
- **上下文积累**：哪些函数有历史坑、团队编码风格、架构决策的 why——这些喂给新 Agent 要重新学
- **信任校准**：知道它在哪些场景会犯错、哪些 prompt 能精准触发——人机磨合需要时间

类比修正：Coding Agent 的护城河不是"微信式关系链锁定"，更像"IDE 式肌肉记忆锁定"。你用惯了 IntelliJ，即使 VS Code 免费且更好用，你也不一定迁移。

## 残酷终局推演

- **底层模型层**：伯特兰价格战，一路贴边际成本。活下来的靠 GPU 规模和推理效率，不靠品牌
- **应用层 Agent**：卷集成深度和上下文积累。谁成为开发者"默认操作系统"，谁占住肌肉记忆生态位
- **最终格局**：可能 2-3 家巨头活下来，因为只有它们有资本贴 token 价格，同时有工程能力维护复杂集成

如果你相信 AI 能做到"一键迁移工作流且迁移得比原来更好"——那所谓护城河会在瞬间消失。但这里有个悖论：如果 AI 真能做到这点，它本身就成了那个"终极操作系统"，底层 Coding Agent 变成了水电煤。护城河没有消失，只是向上移动了一层。

## 一句话总结

Token 市场是数字时代第一次、也是最接近教科书伯特兰悖论的真实案例。它证明了：同质化 + 正边际成本 + 无摩擦切换 = 价格趋近成本。也证明了：要逃离这个宿命，要么有产能约束（GPU），要么有转换成本（工作流绑定）。两条路都不容易，所以 AI 公司的毛利率，大概率不会像 SaaS 那样"躺赚"。
