01Six domains, not six islands

Six domains as nodes, cross-domain relationships as edges. Only documented references are drawn; imagined synergy is not.

  • Node size scales with the number of projects labelled with that domain (a project may belong to several domains, so the counts sum to more than the project total).
  • Edge width scales with the number of project relationships between the two domains; numeric labels mark only the 5 densest edges.
  • Threshold rule: for each project pair the relations recorded on both sides are merged and the larger reference count is kept; pairs with 1 reference or fewer are treated as noise and dropped. This graph keeps 14 edges covering 75 project relationships.
  • Evidence basis: code references are word-boundary text matches in local source (the graph.py method); doc references are registrations in READMEs, documents and configuration. Source co-occurrence is not a business dependency, and this graph claims no call relationships.
