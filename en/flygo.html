Don't Throw That Old PC Away

No new hardware, no Linux adventure — one Windows PC becomes a complete NAS.

  • Zero extra hardware — no boutique NAS, no new build; an idle Windows PC steps up.
  • Complete NAS features — file management, movie library, photo backup, multi-device sync, remote access, nothing missing.
  • Keeps the Windows ecosystem — no Linux migration; existing software, drivers and peripherals keep working.
  • The browser is the console — everything is managed from one web panel, no commands to memorize, no remote desktop.

Open the Browser — That's the Server Room

Quick actions, housekeeper components, service status — a mirror of the whole NAS.

The overview page condenses daily operations into one row of buttons: copy entry, night mode, reboot, safe eject of external drives — one click each.

  • Housekeeper components — start and stop webcli, Syncthing, Homepage and other core components, with live status.
  • Service status wall — 26 services: which are up, which are down, whether port mapping is right — one glance.
  • External drive protection — safe eject, and the sync scheduler only runs while the external drive is online, so no data is lost.

Self-Hosted Essentials, Out of the Box

A NAS is more than file sharing — movies, photos, passwords and automation, the whole suite in one go.

  • Movies & photos — Jellyfin for watching, Immich for photo backup, MeTube for video downloads.
  • Files & cloud drives — alist aggregates cloud drives, local file management, WebDAV access anywhere.
  • Productivity & security — Vaultwarden for passwords, AdGuard for ad blocking, Uptime Kuma for monitoring.
  • Automation & development — n8n workflows, code-server (VS Code in the browser), qinglong cron jobs.
  • Unified container management — Portainer manages containers; start, stop and rebuild all in the panel.

Data at Home, Reachable Anywhere

Sync, mesh networking, mobile access — away from home, your data is still at hand.

  • Multi-device sync — Syncthing syncs files directly between devices, no third-party cloud in between.
  • Mesh networking — Tailscale connects home and remote devices into one network, direct connection everywhere.
  • Mobile access — photos and files from the phone flow into the NAS automatically; backup you never think about.
  • Access control — who sees what, and from where — written down and enforced.
