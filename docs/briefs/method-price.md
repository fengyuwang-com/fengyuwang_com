# brief — method-price《这套方法，自带价目表》

## ① 想法一句话
任何一套可活下来的方法都明码标价——漫长的等待、巨大的工作量、放弃暴富、判断错了照样阶段性踏空；不肯付价的人，等于没买这套方法。

约束（原文自我坦诚，四条全用）：
- "极度考验耐心，低估凹池左侧布局需要漫长等待，容易踏空短期题材泡沫"
- "研究工作量巨大，需要逐家企业拆解长期核心资产"
- "不适合短线暴富诉求，拒绝高杠杆、纯题材炒作"
- "宏观利率判断出现偏差时，整体仓位会出现阶段性踏空"
优势（作平衡与边界，可选二）：
- "风控前置，四大铁律+分层仓位，大幅控制最大回撤"
- "全部指标可量化（利率、估值、均线、产能），不靠主观情绪、小道消息"
