# brief — four-iron-rules《方向对了，还要不越线》

## ① 想法一句话
选股方法论之上还压着四条顶层铁则——家国、息价、坐标、取舍：任何操作不能违背，违背了赚的也是侥幸，亏的是必然；坐标已有专篇，本篇立其余三条。

## ② 素材引文逐字+出处（源: doubao/raw_日常号_补爬_2026-09-09/38434976035703810.jsonl idx=0，奇衡DK 体系笔记，第三方框架，行文用"有一套体系"引述视角）
- "全文反复统一四大铁则，任何操作不能违背，是体系风控总纲。"
- "家国原则（第一原则，仓位底线）：净持仓长期与国家产业、经济发展方向一致，做多国产替代、高端制造、内需消费；规避长期与政策导向反向赛道；危机行情坚定看多国内资产（2020全球恐慌、2022、2023市场底部论述）。"
- "息价原则（宏观择时核心）：利率周期决定大类配置：低利率环境持续增配权益股票；高利率周期转向债权、高股息防御；2020、2023国内降息周期持续看多A股的底层依据。"
- "取舍原则（风控核心，克服人性贪婪）：主动放弃过热赛道潜在收益，规避泡沫崩盘风险；别人贪婪我离场（2021分批清仓比亚迪、锂电板块），不追求每一段行情都吃到，只赚高安全边际、预期差的钱。"
- "坐标原则（估值博弈核心）：以同业、历史周期、海外对标建立坐标做价差博弈，不赌绝对价格高低。"（只作四条并列点名，不展开——已有 coordinate-principle 专篇）

## ④ 八法选法
立（三条铁则各立一句可执行判据）+ 破（"原则是虚的"与"顺着政策追热点"两头破）+ 阶（四条铁则有先后：家国是底线，息价定比例，坐标定贵贱，取舍定纪律）。

## ⑥ 形状

## ⑦ 不适用边界
- 不荐股不给点位；2020/2022/2023 底部论述、2021 清仓只作语料复盘引用，不做当下行情判断，不编测算。
- 第三方体系引述视角（"有一套体系"），不冒充站长自创，不点名。
- 与 coordinate-principle 分工：坐标原则只四字点名+"另有一篇"，不重复任何内容。
- 与 art-of-selling 分工：取舍讲买入侧的放弃（不进场），不讲卖出时机与止盈习惯。
- 与 survive-the-cycle 分工：那是乱世生存原则（人人可用），本篇是持仓者的顶层约束，家国/息价内容不与其重复。
