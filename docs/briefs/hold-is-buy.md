# Brief — hold-is-buy《持有就是买入》

- 站长原话（素材围墙内）:
  - "我觉得持有这个想法很奇怪。因为你持有的话，你不等于在买入吗？"
  - "我觉得这个分析师才是真正的涨的时候看涨，跌的时候看跌。"

- 素材数字（同一语料内）: 腾讯 0700.HK 45 家投行跟踪：42 买入/强力买入、2 持有、1 卖出；TipRanks 统计明星分析师胜率 50%-55%，超 60% 者凤毛麟角。
- 结构（立—破—成）:
  - 立: 评级分布是奇观——买入满天飞，卖出凤毛麟角；真正的中性市场不长这样。
  - 破: 反方说"持有是冷处理、留余地"——破: 持有就是买入，持有一天的每一步都是继续做多；胜率统计公开可查仍不追责，目标价打脸也要上调（站长原话的 550 场景）。
  - 成: 评级不是研究是产品，卖的不是预测是掩护；散户要问的是分红回购与"三年不涨每年拿多少现金"。
- 八问自查: 素材全出自该语料；无围墙外事实（42/2/1 与 50-55% 为对话内数字）；无直角引号；零痕迹；判断收口；与 four-filters/retail-edge/tonghuashun-paradox 均不同角度。
