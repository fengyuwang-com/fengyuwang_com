# brief: coordinate-principle 《贵不贵，要看跟谁比》

## ① 一句话
单独问一只股票贵不贵，是问错了问题——估值不是绝对数，是坐标：跟同业比、跟自己的历史周期比、跟海外对标比，赚的是价差博弈的钱，不赌绝对价格高低。

1. idx=0: "坐标原则（估值博弈核心，区别静态估值）：不单独判断个股贵贱，以同业、历史周期、海外对标建立坐标做价差博弈，不赌绝对价格高低。"
2. idx=0: "案例：对标奈飞测算阅文IP价值、招行对标邮储、特斯拉对标比亚迪估值差。"
3. idx=0: "所有战略切换以基本面拐点+市场情绪冷热双验证，单一估值高低不做切换依据。"
4. idx=0: "银行特殊筛选规则：PB>1才纳入，破净隐含坏账计提不足风险，摒弃低PB抄底思维。"
5. idx=0: "品牌不能计入估值，未兑现业绩的隐蔽资产无意义。"（全聚德案例）

## ③ 对手戏回合表（反方为语料中被引述的真实观点）
| 回合 | 反方 | 正方回应 |
|---|---|---|
| 1 | 大众口径："低 PB 就是便宜，破净就能抄底。"（语料明确摒弃的低PB抄底思维） | 破净隐含坏账计提不足风险——便宜可能是陷阱的标价 |
| 2 | （延伸）"这支股票历史上从来没这么低过。"——语料口径：单一估值高低不做切换依据，要基本面拐点+情绪冷热双验证 | 没有坐标的"历史最低"只是孤独的数字 |
| 3 | （延伸）"跟谁比不是我说了算？"——语料口径：坐标三件套是同业、历史周期、海外对标（奈飞↔阅文、招行↔邮储、特斯拉↔比亚迪） | 对标选错，结论全错；所以坐标是功课，不是借口 |

## ⑥ 形状
误读（贵贱是绝对数）→ 坐标三件套 → 双验证门槛 → 边界收口（坐标告诉你相对位置，不告诉你方向）。
标题：《贵不贵，要看跟谁比》；副题写实。谐一笔可用（买房类比），不油滑。
