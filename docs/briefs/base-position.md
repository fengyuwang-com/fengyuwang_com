# brief — base-position《人无底仓不富》

## ① 想法一句话
账户里必须有三笔分开的钱——穿越牛熊的底仓、快进快出的弹性仓、强制留存的现金蓄水池；富不起来的根源往往不是选错股，是把三种钱混成一笔，底仓被波动动摇，弹性仓被套成长线。

## ② 素材引文逐字+出处（源: doubao/raw_日常号_补爬_2026-09-09/38434986634566146.jsonl 基于 1911 篇雪球原文，第三方框架，行文用"有一套体系"引述视角）
- "核心总论点：人无底仓不富。区分两类资金，严格分离，绝不混为一谈。"
- "3-5年中长期底仓：匹配'不变基本面'低估值资产（高股息、垄断制造业、核心赛道龙头），穿越牛熊，不频繁交易……操作规则：只有基本面永久破坏才清仓，单纯估值波动不卖出。"
- "波段弹性仓：跟随利率、板块趋势、短期估值凹池滚动操作，快进快出，严格设止盈止损。"
- "现金蓄水池：任何阶段强制留存现金，市场恐慌、估值深坑才有资金布局；原文金句：暴跌无现金，再多理论毫无用处。"
- "成熟体系必须两者结合：底仓左侧低吸，弹性仓右侧顺势，单一模式容易大亏。"

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【一把梭论】"看准了好公司就该全仓押上，分仓是弱者的自我安慰，收益被现金拖平。"——接法：全仓押中的前提是每次都看准，而单一模式容易大亏是语料原文写死的结论；账户只有一笔钱时，每一次波动都直接威胁生存，底仓该有的耐心根本没有存在条件。
2. 【纪律无用论】"钱分三份只是记账游戏，该亏还是亏，关键在选股。"——接法：三种钱的纪律不一样——底仓只有基本面永久破坏才清仓，弹性仓严格止盈止损，现金强制留存；混在一笔里，这三套纪律互相打架：波段的情绪会传染给底仓，底仓的耐心会麻醉弹性仓。选股决定买什么，分仓决定拿不拿得住。
3. 【现金浪费论】"现金不产生收益，牛市里持有现金就是亏。"——接法：现金买的不是收益，是暴跌那天的入场资格——"暴跌无现金，再多理论毫无用处"；牛市里它拖平收益，是为极端时刻付的保费。

## ④ 八法选 1-3
立（三笔钱的结构）、破（一把梭与混仓）、等（三种钱三套纪律的对照）。

## ⑦ 不适用边界
- 空仓等待的心性归 sit-out-in-cash（现金蓄水池只写"强制留存"的结构角色，不重复"看不懂不打"）。
- 浮盈滚存/零成本持有归 cost-to-zero，底仓规则不展开滚存。
- 分散比例归 diversify-net，本篇不写单票/赛道上限。
- 定投工具归 ubw-index-drip，本篇不写指数。
- 不荐股、不给点位、不给任何当下仓位建议；三笔钱不给具体百分比（语料无统一比例，编造即违规）。
- 禁"买的不是X是Y"句式；禁直角引号；en 标题不带句号。
