# brief — time-is-free

## ① 想法一句话
当功能免费之后，价格只能靠意义撑——定价的依据早已从"它做什么"换成"它让人成为谁"。

## ② 素材引文（逐字，出处：~/Documents/private-AIExport/doubao/conversations/Creating Perceived Value in Products_551874.md）
- 讲者（收藏手表多年）："我很久以前买的这块表，花了大概5000美元……现在这块表价值25000美元。我本可以花大概40美元买一块斯沃琪手表，但我没有。"（另处：斯沃琪"在香港大概卖80美元左右"）
- 功能已死："真的有人需要手表吗？不，当然我们不需要手表，因为我们每个人都带着智能手机……如果我想知道世界上任何一个城市的时间，基本上按两个键就可以查到。所以从功能上来说，看时间这方面，没有人真正需要手表。"
- 百达翡丽广告："你实际上永远不会真正拥有这个品牌的手表。你只是在为下一代保管它。""他们有没有说过'买我们的手表吧，因为我们的手表报时最准'？没有。……他们甚至有没有说过'买我们的手表'？没有。"（整支广告只在心理原因上，该公司称之为"传承系列"）
- 手袋平行例："你可以花5万美元买一个爱马仕的柏金包，它做的事情其实和那些便宜的包完全一样。"
- 机制命名："他们不是根据功能来定价，而是根据心理价值来定价……基于价值的定价。"

## ③ 对手戏回合表
| 回合 | 反方（最强版） | 正面接法 |
|---|---|---|
| 1 | "80美元和5万美元的表都看时间，买贵的纯粹是智商税，虚荣定价撑不久。" | 接一半：如果产品卖的是"看时间"，这个批评全对。可看时间已经免费了——没人需要手表，手表照样卖出25000美元，说明这钱从来不是付给功能的。税不税，先看买的是什么。 |
| 2 | "传承广告是话术，表还是那块表，溢价是营销幻觉。" | 幻觉撑不起三十年：从"报时最准"一句不提到"为下一代保管"，这家公司把承诺从产品寿命挪到超出买家寿命的时段——一句没人核查得到的话，反倒成了最贵的部分。话术骗一次，传承要代代兑现。 |
| 3 | "5000美元变25000美元是投资眼光，跟心理价值无关。" | 增值恰是心理定价的果：因为"你从未真正拥有它"写进了品牌叙事，二手市场才愿意为"传给下一代"付溢价。先有意义，才有账面数字——因果别倒装。 |
| 4 | "那只是奢侈品，普通生意学不来。" | 机制不分贵贱：同一次课里，5万美元的柏金包和街边100港元的包装的是同样的东西。定价的锚不在产品里，在产品帮人完成的自我表述里——这一条对小生意同样成立，差别只在意义大小，不在有无。 |

## ④ 八法选法
正面接（接一半）+ 归因法（把"智商税"改判为"意义采购"）+ 边界划法（功能免费是前提，功能仍稀缺的市场不适用）。

## ⑤ 五气配比
断 3 / 怀 3 / 察 2 / 悯 1（给那个花 40 美元预算、最终多付百倍仍觉得自己赚了的人——他买到的确实不止一块表）/ 谐 0。

## ⑥ 形状
zh 1000-1200 汉字；en 550-750 词。开场：一部手机按两个键就能查世界任何城市的时间。收口判断：功能负责让人进门，意义负责让人掏钱；功能免费那天，价格只好搬进意义里。

## ⑦ 不适用边界
- 不谈投资品估值方法论（增值只作果不作论题）。
- 不引申"一切定价皆心理"——功能仍稀缺（药品、算力）的市场不适用，边界要写明。
- 品牌只用语料内的（Swatch/百达翡丽/爱马仕/手机泛指），数字封顶：40/80/100港元/5000/25000/50000美元。
- 不编百达翡丽广告年份、销量等语料外事实。
