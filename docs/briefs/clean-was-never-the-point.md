# brief — clean-was-never-the-point

## ① 想法一句话
最普通的商品也能翻身：不卖功能卖信念，前提是说到做到——信念不是广告词，是账目。

## ② 素材引文（逐字，出处：~/Documents/private-AIExport/doubao/conversations/Creating Perceived Value in Products_551874.md）
- 商品困境原话："每个人都生产肥皂，你可以在任何地方买到，而且价格很便宜。那么究竟为什么你要多花一点钱去买多芬的肥皂呢？"
- 广告反问三连："他们有没有说过'买我们的肥皂吧，因为它能把你洗得更干净'？没有。他们有没有说过'买我们的肥皂吧，因为我们的肥皂成分最好'？没有。他们有没有说过'买我们的肥皂吧，因为我们的价格最优惠'？没有。他们做了什么呢？他们向你展示了他们所代表的东西。"
- 广告内容（法医画像师短片）："我是一名法医艺术家。我在1993年于联邦调查局学院接受了合成画像艺术的培训。从1995年到2011年，我在圣何塞警察局担任警察画像师。"——女性自述 vs 陌生朋友描述，朋友描述的好看得多。"我们对自己的认知通常有点苛刻，而且并不客观，而实际上世界并不是这样看待我们的。"（"你比自己认为的更美丽"）
- 说到做到："他们向各种各样支持女性问题的慈善机构捐款。所以他们说到做到，并且不断开展这类活动来强化一个事实……"
- 效果与命名："曾经多芬只是另一个肥皂品牌，他们在一个竞争非常激烈的商品化市场中竞争……直到他们推出了这种方法，然后他们的销售额增长了，市场份额也增加了。"（学生侧提到"品牌行动主义"一词）

## ③ 对手戏回合表
| 回合 | 反方（最强版） | 正面接法 |
|---|---|---|
| 1 | "这是操纵认知，跟百事盲测营造高价值感没有区别，信念营销是道德风险。" | 区别在账目：百事是让人相信味道更好，信念本身经不起对账；多芬说"你比自己认为的更美"，跟着的是给女性议题的真金白银捐款——说了就做，账目可查。操纵造幻觉，信念造记录。 |
| 2 | "肥皂就是肥皂，信念改变不了产品参数，低价竞争者终会赢。" | 参数确实没变，变的商品架前那半秒钟：走过货架时那句"我知道他们是谁、他们代表什么"——比价需要时间，认同不需要。商品化市场里，参数人人相同，唯一复制不走的就是这份联想。 |
| 3 | "不知名的新品牌拍这种广告没人看，风险太大，是成名品牌的特权。" | 顺序反了：多芬拍这支片子之前"只是另一个肥皂品牌"，在红海里保份额。不是成名之后才有资格谈信念，是谈了信念并兑现才成的名。风险真实存在，但它是入场费，不是特权凭证。 |
| 4 | "低价市场消费者只看价格，这套在价格敏感的市场行不通。" | 价格敏感拦不住溢价，拦住溢价的是没有差别。同一堂课讲者的判断：如果价格敏感真的一票否决，奢侈品就不会在任何市场卖出数十亿美元——差别只是意义造得够不够大，不是市场给不给机会。 |

## ④ 八法选法
正面接（接一半）+ 对照法（百事式幻觉 vs 多芬式账目）+ 边界划法（信念必须可兑现、可查账，否则滑回操纵）。
