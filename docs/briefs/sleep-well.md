# brief — sleep-well《买这只股票，睡得着吗》

## ① 想法一句话
买入标的一条底线：必须由硬核资产支撑，不靠商誉、预期讲故事；支付价格相对可变现资产要有六七折以上折扣，无巨大减值暴雷隐患——这套体系管它叫"睡得着股票原则"，检验的不是收益，是夜里闭不闭得上眼。

1. "睡得着股票原则（个股风控底线）：买入标的必须硬核资产支撑，不靠商誉、预期讲故事；支付价格相对可变现资产有6-7折以上折扣，无巨大减值暴雷隐患。"
2. "四大底层交易原则（宏观+个股通用风控，贯穿全文）"——睡得着原则与逆向买入、先胜而后求战、取舍并列（可一笔交代序列地位）。
3. "高商誉、大股东高比例质押、持续负现金流企业，直接大幅下调估值或排除。"（避雷规则）
4. "拒绝贴现远期虚无增长，优先研究当下可验证、长期不变的生意事实，反对靠幻想预判未来。"
5. "所有股票都是垃圾，只不过某些时段会上涨。"（底层认知：本金安全优先，收益其次——睡得着原则的根）
授权数字：6-7 折折扣（写作可作"六七折"），无其他数字。

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【折扣苛刻论】"六七折的好资产上哪儿找去？按这个标准一年也开不了几枪，机会全等没了。"——接法：这条原则的第一收益不是买得便宜，是跌的时候睡得着——本金安全优先、收益其次写在体系两条铁律的前一条；开不了枪的年份，本来就不是扣扳机的年份。
2. [Story 支撑论] "优质公司看的是成长性，商誉是品牌价值，预期兑现就是超额收益，算那么死错过好公司。"——接法：商誉和品牌是两本账，商誉是并购付的溢价，减值起来不商量；远期虚无增长拒绝贴现，当下可验证、长期不变的生意事实才进估值——预期兑现前的每一晚都要有人睡得着。
3. 【底线僵化论】"硬资产、折扣都是静态尺子，公司是活的，昨天不达标今天可能达标，等它变好再买也一样。"——接法：睡得着原则是排除法不是评分法——商誉高、质押高、现金流为负的先划出去，尺子钝，钝得有道理；等它变好可以，那是另一只票的另一门功课，底线本身不为期待让路。
