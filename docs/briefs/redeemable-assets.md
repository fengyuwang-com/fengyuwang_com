# brief — redeemable-assets《算得进估值的，才算资产》

## ① 想法一句话
账面上有，不等于估值里能算：品牌、未重估不动产不能直接计入估值，只有能转化持续现金流的才算有效资产——"可兑现"是资产与虚资产的分界线。

## ② 素材引文逐字+出处（源: /tmp/corpus_38434986634566146.txt 基本面实操第四步 + /tmp/corpus_38435110387364610.txt，奇衡DK 体系，第三方框架，行文用"有一套体系"引述视角）
- "第四步：区分'可兑现资产'和账面虚资产。明确批判：品牌、未重估不动产不能直接计入估值，只有能转化持续现金流才算有效资产。"
- "巴菲特对可口可乐品牌的解读存在误导，原文明确提出。"（一笔对照，不展开人身评价）
- 划界用（corpus2）："云南白药、片仔癀的保密配方与品牌心智，是历史积淀形成的稀缺资源。"——品牌可以是护城河（不变资产），但不自动等于可计入估值的资产；两个身份要分开算。
- 配套语境："第一步：剥离短期扰动，提取'不变核心资产'。"（先提资产，再判可兑现，顺序不能反）

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【报表实在论】"品牌在资产负债表上是值钱数字，白纸黑字，凭什么不算。"——接法：报表数字是历史成本或评估价，估值只认一件事：能不能转化成持续现金流；写进表的是记账，转化得出来的才是资产。
2. 【保守吃亏论】"把品牌、物业都不算进去，会错过所有伟大公司。"——接法：不入价格，入判断——品牌算护城河，不算价差；决定买不买的锚里没有它，决定它是不是好公司的答案里有它，两个用途不冲突。
3. 【等兑现论】"物业重估一翻几倍，先按账面算，等它兑现再补不迟。"——接法：兑现不是等来的，是转化出来的；转化不了的账面数放十年还是账面数，把它当资产放进估值，只是把愿望记成了钱。

## ④ 八法选 1-3
立（可兑现分界）、破（账面≠资产）、问（转化路径在哪推进）。

## ⑦ 不适用边界
- 与 coordinate-principle 分工：那边定三维价格锚，本篇定哪些资产有资格进锚，不写 PE/PB 分位数。
- 巴菲特只作观点对照一笔，不展开、不做人身评价；白药片仔癀只作"护城河身份"例证名词一笔，不给任何估值判断、不荐股。
- 不写任何具体公司估值数字、重估案例编造；品牌与商誉的减值会计细节不展开（商誉归 minefield-list 排雷语境）。
