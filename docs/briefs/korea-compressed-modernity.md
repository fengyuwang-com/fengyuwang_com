# brief: korea-compressed-modernity 《韩国人不是赌性重》

## ① 一句话
韩国全民炒币炒芯片，不是因为国民爱赌，是三十年走完两百年路的社会，把普通人逼进了投机这条唯一的窄门——周期换标的，不换宿命。

## ② 素材引文（逐字，出处 doubao raw_日常号_补爬_2026-09-09/38431623301651714.jsonl）
1. idx=48: "比特币牛市时，上班族白天盯K线、大学生贷款冲合约，退休老人把养老金砸进加密市场，全球四成的比特币交易量来自这个五千万人口的国家。"
2. idx=48: "这个国家用短短三十年，走完了西方两百年的工业化、城市化、现代化路径，也就是社会学里说的「压缩现代性」。"
3. idx=48: "从战后赤贫到汉江奇迹，一代人就完成了从农业国到工业国的跃迁；可1997年亚洲金融风暴直接击穿国家信用，IMF接管经济，全民被迫捐金还债。"
4. idx=48: "高速增长期结束后，财阀垄断了绝大多数社会资源，普通人靠读书、内卷、加班，再也跨不动阶层。劳动收入的增速，永远跑不赢资产价格的涨幅。"
5. idx=48: "信贷宽松时，全民加杠杆入场，相信「这次能改变命运」；美联储加息收水，债务集中到期，泡沫破裂，又是一代人的财富被收割。"
6. idx=48: "你以为是韩国人贪，其实是这套压缩现代性的秩序，把所有人逼进了投机的死胡同。集体创伤带来的不安全感，阶层固化带来的无力感，意义消解带来的虚无感，最后都化成了对资产泡沫的执念。"
7. idx=54: "普通国家现代化百年缓步完成，韩国用30年走完西方200年工业化+资本化进程，形成「压缩式创伤」。"

## ④ 八法选 1-3
三层递进（疯狂现象→压缩现代性→周期机制）；分篇挂牌（国别案例，接在行业周期之后）；问句收口。
