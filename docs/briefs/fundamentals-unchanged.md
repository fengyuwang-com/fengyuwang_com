# brief: fundamentals-unchanged 《基本面，是基本不变的那一面》

## ① 一句话
大多数人把"基本面"当成最近一季的业绩表，可真正的基本面是不随季度变的那一层——商业底层、永续需求、壁垒、现金流模式；短期业绩是噪音，永久受损才是信号。

## ② 素材引文（逐字，出处 doubao raw_日常号_补爬_2026-09-09/38434976035703810.jsonl，站长整理的第三方投资体系笔记）
1. idx=0: "基本面≠单季度/单年业绩；基本面是企业长期不变的商业底层、行业永续需求、不可替代壁垒、稳定现金流模式；短期业绩波动只是噪音。"
2. idx=0: "研究基本面的目的不是解释涨跌，而是克服贪婪恐惧，在极端行情下区分'企业永久受损'和'短期情绪砸盘'。"
3. idx=0: "业绩一次性亏损（东阿阿胶去库存、多氟短期亏损），只要底层商业模式不变，属于情绪错杀；行业逻辑永久破坏才永久离场。"
4. idx=0: "财报是过去结果，模式决定未来，不能反向用报表选股。"
5. idx=0: "重点观测指标：经营性现金流、负债结构；短期利润波动可容忍。"
