# brief — complaint-flip-side《投诉的人，还没走》

## ① 想法一句话
投诉不是损失的终点，是翻过来的机会——肯打电话来骂的客户还愿意跟你打交道，处理得当，他们会变成最满意的那批人。

## ③ 对手戏回合表（3-6 承重回合）
- R1 反方「沉默多数论」：投诉的只是少数爱出声的，统计上该看沉默客户的平均值。→ 正面接：沉默恰恰是最贵的信息——讲师的指数里投诉是可以减去的负项，可没投诉的不满并没有消失，它只是不再被测量。肯骂的人给你免费的诊断，不骂的人直接退出样本。对沉默的过度放心，才是流失的温床。
- R2 反方「补救成本论」：为了平息一次投诉投入这么多，不如把钱花在让多数人满意上。→ 接：讲师说 best practice 公司把投诉当机会处理，不是出于慷慨，是算得过账：被妥善处理的投诉人，结果满意度反而更高（"wind up with a very satisfied customer"）——同样一笔钱，花在本来就要走的客户身上，回报结构完全不同；何况投诉处理是流程不是施舍，做好了是能力，不是成本。
- R3 反方「职业投诉论」：有人投诉就是为了要赔偿，认真接招会被拿捏。→ 接：流程化的投诉处理防的正是这个——按满意度指数的框架走（期望落差在哪、感知质量差在哪），先诊断再补偿；给钱只是诊断之后的一种药。把所有投诉都当讹诈，等于把所有病人都当装病。
- R4 反方「指标游戏论」：把投诉写进指数，公司会想办法让客户别投诉（设门槛、拖时间），指标反而变好看。→ 接：这不是指数的错，是把"投诉少"当成了目标——指数里投诉是减项没错，但它前面还有期望、感知质量、感知价值三项；砍掉受理渠道，减项少了，其他三项塌得更快。测什么不重要，别把测量对象当靶子。
