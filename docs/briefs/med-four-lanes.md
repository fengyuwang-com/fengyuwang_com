# brief — med-four-lanes《同是医药，四种活法》

## ① 想法一句话
"医药"不是一个赛道，是四门生意：血制品吃牌照供给刚性、中药吃库存周期、创新药吃研发投入（长期高估回避）、仿制药吃集采周期——同一板块内部，剧本完全不同。

## ② 素材引文逐字+出处（源: /tmp/corpus_38434986634566146.txt 第六部分医药板块，第三方框架，行文用"有一套体系"引述视角）
- "血制品（上海莱士）：牌照壁垒、供给刚性，长期底仓赛道。"
- "中药（东阿阿胶）：老字号壁垒，库存周期5年，3-5年一轮去库存周期，底部布局。"
- "创新药（药明康德）：研发投入高，长期高估回避。"
- "仿制药/原料药：集采周期波动，只在极致低估跟踪。"

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【板块同质论】"都是医药，政策一起涨一起跌，分那么细没有意义。"——接法：涨跌同步是情绪层的事，研究是基本面层的事；四条线的锚是四种东西，情绪可以同涨同跌，锚不会。
2. 【细分内卷论】"研究到这么细，普通人根本做不到。"——接法：做不到的不必做——分不清的细分就不碰，可选项永远比选项多；分清四条线只需要知道每条线吃哪碗饭，不需要成为行业专家。
3. 【低估一篮子论】"分不清就都买点，医药长期向上。"——接法：长期向上的是行业，不是每一笔买进的价格；创新药长期高估、仿制药集采压价，接错剧本的"长期持有"拿的是别人的剧本。

- 上海莱士、药明康德只作细分例证名词，不给任何当下判断、不荐股、不写估值数字。
