## ③ 对手戏回合表（反方无人称）
1. 开篇：10 亿美元、6000 万月活，这笔账按人头算是笔冤枉钱——按时间算才知道买了什么。
2. 反方一（有人说）：天价买一个已经成型的产品，溢价离谱，自己建一个不就行了 → 驳：自建省的是对价，赔的是时间——短视频赛道的窗口期不等人，从零冷启动到 6000 万月活要多少年，竞品就在旁边看着；收购买的是"现在就有"，避开与西方社交巨头在成熟市场的红海正面消耗。
3. 反方二（也有人说）：用户是买来的，不是留下的，收购来的用户迟早流失 → 接一半：这是真风险，评估里明明白白列着——两个用户群的调性冲突、北美团队与总部的管理矛盾、短期增长长期留存不足的三问，一问都没过时。再驳：风险存在不等于交易失败，只等于对价之外还要付整合成本；账上有两栏，只看一栏做不了判断。
4. 反方三（还有人说）：买来的地位没有护城河，别人也能买 → 收：能买的都不是护城河本身——护城河是买来之后把青少年需求、本地运营经验消化成自己的能力；交易只是入场券，消化才是壁垒。颠覆性创新挖的是巨头没顾上的需求缝，缝在谁手里不重要，谁先站进去才重要。
5. 收口：收购的定价从来不该按资产算，该按绕过的路算——省下的红海年月、买到的先手，才是那张 10 亿美元账单的科目。

## ④ 八法选 1-3
对账法（按人头算 vs 按时间算）、两栏账法（对价栏与整合成本栏）。
