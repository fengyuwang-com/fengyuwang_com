# brief — certainty-ladder《仓位跟着确定性走》

## ① 想法一句话
配置的第一问不是"看好什么"，是"对什么有多确定"——这套体系按确定性给资产排座次：确定性最高的烟蒂折价股重仓底仓，优质但贵的龙头只挂观察仓，高波动板块用转债和ETF替代正股，新兴赛道当期权轻仓，看不懂的不碰；仓位是确定性的函数，不是胆量的函数。

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. [均匀配置论] "好公司就值得买，哪有那么多座次？确定性好坏都是主观打分，不如优质资产均匀分。"——接法：均匀分的前提是各资产风险同质，而烟蒂折价股与产业期权本来就是两种风险容器；确定性决定的是仓位上限——最确定的拿最重的仓，最像彩票的拿彩票的仓，次序不是品味是算术。
2. [踏空观察仓论] "好公司挂观察仓干等，涨上天了怎么办？龙头就该一直拿着。"——接法：写死的规则是"等行业利空、深度回调出折价再介入，热门阶段全程观望"；观察仓不是不研究，是把买入权留给折价——好公司买贵了，确定性再高也变成另一种冒险（好公司≠好价格，一笔划界归 good-company-good-stock）。
3. [赌性合理论] "新兴产业就是要重注 early conviction，轻仓等于没做，期权思维太保守。"——接法：体系给新兴赛道的定性就是产业期权博弈——期权的特点是小注、分散、认赔；把期权当重仓股做，赔率结构就反了：赢是小概率的暴利，输是大概率的清零。

## ⑦ 不适用边界

- 与 convertible-hedge 分工：转债替代只作一层座次提及（"用转债替代正股"），不展开案例与机制。
- 与 ubw-index-drip 分工：ETF 兜底只一笔，不展开。
- 与 sleep-well 分工：避雷区只列体系原文四类作"全程规避"一层，"睡得着"检验归那篇。
- 与 good-company-good-stock 分工：好公司坏价格只划界一笔，不重述。
- 与 position-cap 分工：那篇讲总仓位纪律，本篇讲仓内座次，不写大盘点位。
