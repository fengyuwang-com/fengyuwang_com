# Brief — credit-machine《信贷是预支的支出》

## 语料出处

## ① 想法一句话
信贷不是钱的搬运，是未来的支出被搬到今天——一个人的支出是另一个人的收入，所以信贷一松人人变富，信贷一收人人变穷，周期就是这么造出来的。

## ④ 八法选 1-3
