# brief — three-rulers《什么资产，配什么尺子》

## ① 想法一句话
三类资产三把尺子：周期股看产能与供给周期、军工看资产注入与长期订单、消费医药看品牌牌照存量客户——尺子跟着资产走，用错尺子量出来的便宜是假便宜。

## ② 素材引文逐字+出处（源: /tmp/corpus_38434986634566146.txt，基本面实操第三步，第三方框架，行文用"有一套体系"引述视角）
- "第三步：区分周期/成长/价值三类资产，匹配估值标准。"
- "周期股（有色、化工、航运）：看产能、供给周期，不看静态PE。"
- "军工：看集团资产注入空间、长期订单。"
- "消费/医药：看品牌、牌照、存量客户。"
- 锚的佐证："军工：长期稳定军品订单、集团待注入优质资产（中航系、航天科工）。"（名词一笔）

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【万能尺论】"一把 PE 尺量所有公司，简单省事。"——接法：尺子错，量出来的便宜是假便宜；周期股的静态低 PE 常常站在周期顶上，语料原文写明"不看静态PE"。
2. 【尺子平等论】"都是资产，凭什么军工看注入、消费看品牌，标准不统一就是主观。"——接法：尺子跟着锚走，各类资产"基本不变的那一面"本来就不同；统一标准才是错，因为锚不统一。
3. 【尺子过时论】"看品牌看牌照是老一套，现在该看流量看增长。"——接法：尺子配资产，不配年代；流量平台是另一类资产、另配一把尺，把增长尺硬套到周期股上才是真正的老一套。

## ④ 八法选 1-3
立（三把尺子）、破（万能尺错觉）、问（这家公司该用哪把尺）。

## ⑤ 五气配比
断3 怀2 察4 悯1 谐0。

## ⑥ 形状
开场问（同一把尺，为什么量出了两个答案）→ 立三把尺 → 每把尺一小节（量什么、为什么）→ 对手三回合 → 收口（先问是什么资产，再问值多少钱）。

## ⑦ 不适用边界
- 与 minefield-list 划界：那边把"周期股不能套消费估值"当作一条雷写，本篇立正面的三把尺，只在对照处一句带过，不重复排雷清单。
- 与 coordinate-principle 分工：那边是三维坐标（怎么量），本篇是选尺（量什么），不出现 PE/PB 分位数操作。
- 与 redeemable-assets 分工：那边判品牌能不能进估值，本篇把品牌当消费医药那把尺的刻度之一，落点不同，不重复"可兑现"论证。
- 中航系、航天科工只作锚的例证名词一笔，不给任何当下判断、不荐股；有色化工航运只作周期类例证列举。
