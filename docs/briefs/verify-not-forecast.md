# brief — verify-not-forecast《不预测，只验证》

## ① 想法一句话
预测和验证是两门相反的手艺：预测是先有结论再找证据，验证是先定标准等市场表态——不预判顶底，等均线、估值、资金给出明确信号再动；靠消息和主观情绪预判行情，属于赌博，不是投资。

## ② 素材引文逐字+出处（源: 38434986634566146.jsonl，奇衡DK 投资思想全拆解（基于1911篇雪球原文），第三方框架，"有一套体系"引述视角）
- "不预测市场，只验证市场：拒绝主观预判顶部/底部，等待均线、估值、资金突破给出明确信号再操作。批判：靠消息、主观情绪预判行情，属于赌博，不是投资。"
- "阻力最小路线：多空充分博弈后，单边上涨/下跌方向，利好会被放大、利空被忽略；操作：只等区间有效突破再跟随，不提前预判拐点。"
- "年线上方：市场处于多头环境，可持有、加仓；年线下方：长期空头主跌段，大幅收缩仓位。"（作"可验证标准"的实例，一笔）
