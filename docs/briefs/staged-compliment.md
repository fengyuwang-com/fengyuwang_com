# brief — staged-compliment《那声夸奖是安排好的》

## ① 想法一句话
好的客户体验不是待人好，是设计好的戏——卖你选不中的第三副眼镜、把夸你的人安排在店门口；体验可以真诚，但真诚是可以排练的。

## ③ 对手戏回合表（3-6 承重回合）
- R1 反方「操纵论」：等在店外的夸奖是雇来的戏，这不是服务是剧本，客户被算计了。→ 正面接：戏是真的演，眼镜真的好看； Ruth 卖的是 option 3 不是最贵的那副——剧本写的恰恰是"对你对"。设计与真诚不是对手，设计是真诚的传动装置。引 Maya Angelou 一句兜底：人忘掉你说什么，忘不掉你让他感觉什么——感觉可以被安排。
- R2 反方「产品硬论」：眼镜好就行，戏多余，好产品自己会说话。→ 接：100 家更近的眼镜店、更便宜的网购都在卖同样合格的镜片；产品决定及格线，决定不了三小时的单程车程。会说话的产品太多，被记得的感觉太少。
- R3 反方「幸存者偏差论」：Ruth 是个例，讲个例是拿彩票得主教理财。→ 接：讲师同一段列的 Mitchell's（1958）、Ways（1964）、Zingerman's（1982）全是几十年活着的同类——共同点不是行业，是都把体验当日常功课；且 Forrester 2016 年研究：体验领先者在营收上显著跑赢落后者（转述，不引具体数字倍数）。
- R4 反方「可复制幻觉论」：那我照抄——雇人夸客户、摆三副眼镜。→ 接：抄动作抄不来判断。Ruth 的判断是"我知道你看不中 option 1，但我先让你自己走到收银台"——剧本是根据眼前这个人现场写的，模板是死的。

## ④ 八法选1-3
主：断（体验≠人品，=设计）+ 察（第五声夸奖才反应过来：好设计的特征是察觉不到设计）。

## ⑤ 五气配比
断 3 / 怀 2 / 察 2 / 悯 1 / 谐 1

## ⑥ 形状
开场自述式案例（第五声夸奖的反转），中段三回合反方，收口：21 年、三小时车程、100 家更近的店——忠诚不是被说服的，是被安排出来的感觉养着的。

## ⑦ 不适用边界
- 不写 B2B、不写定价策略、不写数字营销。
- Forrester 研究只转述结论不编数字；Ruth 案例不补语料外细节（不写店名全称以外的地址、价格）。
- 与 greeting-that-sells-nothing 划界：那篇写公司侧触点记账（推销/不推销），本篇写体验本身是被设计的产品。
- en 标题无句号；不得出现 second-person（Angelou 逐字引文豁免）。
