# brief — not-the-anchor《这些，不算基本面》

## ① 想法一句话
锚的反面也有名单：短期营收、一次性补贴、短期爆款、管理层短期业绩承诺——会随业绩或情绪消失的东西，不属于不变基本面，不能作估值依据。

## ② 素材引文逐字+出处（源: /tmp/corpus_38434986634566146.txt，「基本面就是基本不变那一面」定义节，第三方框架，行文用"有一套体系"引述视角）
- "基本不变的那一面（内在锚）：企业长期、不会随短期业绩、市场情绪消失的硬资产/永续壁垒，是内在价值唯一可靠参照，短期业绩波动不改变锚。"
- "反面排除：短期营收、一次性补贴、短期爆款、管理层短期业绩承诺，不属于'不变基本面'，不能作为估值依据。"
- "股价分为两部分：短期波动（讨价还价+随机漫步）、长期锚定（基本面）。"
- "随机漫步：无逻辑情绪波动、短期资金炒作、消息刺激，不可预测，只可顺势。"

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【业绩即基本面论】"利润表上的增长就是基本面，白纸黑字，凭什么短期营收不算。"——接法：锚的定义是不会随短期业绩消失；会消失的营收撑不起长期估值，它算业绩，不算锚。
2. 【补贴也是钱论】"补贴进来的也是真金白银，到账的现金没有真假。"——接法：钱是真的，来源是一次性的；估值数的是年复一年还在的钱，不是来过一次的钱。
3. 【承诺有据论】"管理层业绩承诺写进公告，具有约束力，怎么能不信。"——接法：承诺是意图，不是资产；兑现路径握在别人手里的东西，够不上"不随情绪消失"这条线。

## ⑦ 不适用边界
- 与 fundamentals-unchanged 分工：那边立"不变是锚"的正面哲学，本篇写反面排除名单，正面定义只作一句引子不展开。
- 与 redeemable-assets 分工：那边判账面资产可不可入估值（品牌/物业），本篇排除的是营收类、补贴类、爆款类、承诺类——不是同一组东西，不重复"可兑现"论证。
- 四个冒充者不点名任何在市公司、不影射当下热点产品；"短期资金炒作、消息刺激"只作随机漫步释义，不展开盘面判断。
