# brief — data-lies

①想法一句话:数据不可信——不理解生意,永远被数据骗;但自己回测过的指标是例外:别人给的指标和自己验证过的指标是两种东西。

②素材引文逐字:
- notes A2.1(篇012):"你盯着那个数据看,永远都是出问题的,因为你不理解那个生意的话,你永远会被数据骗了。""量化投资在本质上就是出问题的,因为你专门看那个数字,你有点入迷了……那个数字它是人编出来的,它也是可以骗人的,它没有 tell everything。"
- 篇252 L309(AI 吸收,用户同款判断):"如果 K 线结构里真的藏着什么'故事'或者可重复的规律,量化基金和机器学习早就把它榨干了,轮不到散户靠肉眼画笔段赚钱。"
- 篇002 L1143(用户):"移动平均线啊,年线年线它确实是指示了那个趋势的……这个我确实自己回测测出来。"
- notes A2.1(篇002 例外条款):区分"别人给的指标"与"自己验证过的指标"。
