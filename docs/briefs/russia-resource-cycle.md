# brief: russia-resource-cycle 《俄罗斯的国运，挂在油价上》

## ① 一句话
坐拥全球顶级资源储量的国家，经济周期却从来不由自己说了算——外围资源国的债务周期绑定美元周期与能源价格，涨靠油价，跌靠制裁，轮回靠全球信贷放水。

## ② 素材引文（逐字，出处 doubao raw_日常号_补爬_2026-09-09/38431623301651714.jsonl）
1. idx=48 第19集草稿: "油价涨的时候，卢布坚挺、全民日子都宽裕；油价跌的时候，货币贬值、通胀飙升、全民财富同步缩水。这个坐拥全球顶级资源储量的国家，却从来没真正掌控过自己的经济周期。"
2. idx=48: "这就是典型的「地缘依附型现代性」——苏联解体后，俄罗斯用休克疗法快速接入全球资本主义体系，没有建立起完整的高端产业闭环，只能靠出口能源、原材料参与全球分工，天然处在全球资本积累体系的外围位置。"
3. idx=48: "1998年主权债务违约，老百姓积蓄一夜蒸发；2014年克里米亚危机后，油价腰斩叠加制裁，卢布贬值过半；2022年俄乌冲突升级，外汇储备被冻结、能源贸易受限，经济再度承受周期重击。"
4. idx=48: "全球资本的中心在欧美，他们掌控着美元信贷的松紧、能源的定价权、地缘的话语权。信贷宽松时，资本涌入俄罗斯，推高油价和资产价格，造一轮虚假繁荣；信贷收紧时，资本快速撤离，油价暴跌，债务暴雷。"
5. idx=48: "地缘是外壳，债务是内核，资源是筹码。只要还处在全球资本体系的外围位置，俄罗斯的周期宿命，就永远逃不开「涨靠油价、跌靠制裁、轮回靠全球信贷放水」的老路。"
