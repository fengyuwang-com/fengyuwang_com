# brief — silicon-cycle

①想法一句话:半导体是周期性最强的行业，低谷期厂商亏钱也得继续生产——沉没成本太高，停产的损失比降价卖芯片更大；所以缺芯、扩产、过剩的循环永远不会消失。

②素材引文逐字（源: doubao/conversations_日常号_补爬_2026-09-09/穿越周期系列内容规划_651714.md）:
- 站长:"比如说SSD，当高峰期的时候不断地扩产，低谷的时候呢？他就这些厂商亏钱都得制造是。"
- 站长:"比如说二三年、二四年那个时候，可能半导体就是一个下行的周期，因为当时那个疫情之后，这些厂商都纷纷扩产，但是后来疫情造成的需求都被满足之后，这些厂商的这个制造还是停不下来，还是需要去解决库存的问题。"
- 豆包吸收:硅周期 3-4 年一轮；重资产属性——一条晶圆厂投资百亿级，产能爬坡需要 1-2 年，停启成本极高；"低谷期亏钱也要造"的核心原因:沉没成本太高，停产损失比降价卖芯片更大；需求错配:产能扩张慢于需求上涨，需求下滑时产能又刚落地，必然过剩。
- 豆包吸收:复盘近两轮周期——2017-2018 年存储超级周期（SSD、DRAM 价格涨 3-5 倍，三星、美光疯狂扩产）；2022-2024 年半导体寒冬（疫情后需求退潮，库存高企，存储价格跌破现金成本，全行业亏损，但厂商依然不敢停产）。
- 豆包吸收:三轮高峰对比——2000 年互联网泡沫期全行业估值顶峰（思科、英特尔 PE 破百）；2017-2018 存储超级周期属结构性高峰（逻辑芯片、模拟芯片一般）；2025-2026 AI 驱动周期属极致的结构性高峰（GPU、AI 存储、光模块历史级景气，英伟达营收一年翻倍，但成熟制程、消费电子、汽车芯片并未全面过热）。
- 豆包吸收:当前判断——AI 算力拉动的上行周期顶部区域，全行业扩产潮已启动，2027-2028 年很可能迎来新一轮产能过剩的下行周期。

③立破成:立"亏钱也要生产"是理性而非疯狂（沉没成本算术）；破"这次景气是历史级所以没有周期"（历史级但结构性，2000 年也曾"历史级"）；成:判断周期位置看开工率和扩产潮，不看景气 headlines。

④查重 notes:cuda-moat（英伟达护城河）、consumer-gpu-dead（消费 GPU 之死）、quant-desymbolization（量化视角）均不同题；four-nested-cycles 只讲周期嵌套框架，本文专讲半导体行业内循环，不重复康波朱格拉内容。
