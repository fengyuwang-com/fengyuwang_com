# Brief — rule-of-three《三个人做不出决定》

## 语料出处
- `~/Documents/private-AIExport/gemini/raw/c_f7ffb9ad467508da.json`（三人决策制的致命陷阱）

## 站长原话（逐字）
- "为什么最高领袖这种决策制度不能设计成三个人？比如说那两个人，对一个人的话就容易去做一个比较正确的、合理的、理性的决定。"

## 素材（仅语料内）
- 三大隐蔽陷阱：1) 联盟动态退化——涉及终极决策必有两人结盟，2 对 1，第三位被彻底边缘化，制度退化为双巨头或一言堂；2) 决策僵局——利益/意识形态/情报来源不一致时无限拉锯，一个不完美但迅速的决定好过完美但迟到三个月的决定；3) 责任隐形逃逸——"当时是 A 和 B 坚持的，我只是顺从多数"，权力共享、责任稀释，反而滋生冒险主义。
- 历史：罗马后三巨头（屋大维、安东尼、雷必达）→ 雷必达边缘化 → 双雄对决 → 帝国；苏联三次"三驾马车"（列宁死后、斯大林死后、赫鲁晓夫下台后）都只是过渡期，最硬的一方清洗另两人，重回一号人物。
- 两个替代方案：方案 A 集体领导+分管（5/7/9 单数更多，各管一摊，责任田明确）；方案 B 首长保持一人保效率，把监督权外置（立法管钱包、司法管违宪）。
- 金句素材：在权力的地心引力面前，三人平衡只是转瞬即逝的幻觉——要么分裂，要么退回一言堂。

## 立破成
- 立：站长提议——三人投票 2 对 1，用多数决逼出"正确、合理、理性"的决定，直觉成立。
- 破：反方是"多数决机制本身自带纠错"。破法：三人组里的多数决不是纠错机制而是夺权机制——同盟一次形成就固化，票型永远 2:1，投票变成了走过场；僵局与责任稀释进一步掏空它。
- 成：制衡的真方向不是把最高位置拆成三份，而是把"决策权"和"监督权"拆开——单数更多人分管一摊，或一人拍板+体外监督。多数决适合选人，不适合做最高层结构。
