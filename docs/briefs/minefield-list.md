# brief — minefield-list《排雷清单》

## ① 想法一句话
选股的第一步不是找好公司，是排掉必死的：一套四条的排雷清单——注水股、伪转型、周期股套消费估值、高市盈率热门赛道——每条都是踩过的人用钱换来的反向校验，先排雷，才轮到谈价值。

## ② 素材引文逐字+出处（源: 38434976035703810.jsonl idx=0，奇衡DK 体系笔记，第三方框架，"有一套体系"引述视角）
- "实战避坑逻辑（所有理论的反向校验，过滤高风险标的）：1. 警惕'注水股'：IPO包装、资产虚增、无持续现金流企业，远离；2. 规避伪转型概念：券商财富管理、跨界造车、无技术支撑多元化（美团盲目多元化是价值毁灭案例）；4. 周期赛道天花板陷阱：锂电车、纯整车行业强周期，不能套用消费股长期估值逻辑；5. 远离高市盈率热门赛道：全民一致看好时，100倍以上动态市盈率无法靠增长消化。"
