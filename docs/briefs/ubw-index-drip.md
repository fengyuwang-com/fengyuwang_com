# brief — ubw-index-drip《跌，是定投的燃料》

## ① 想法一句话
散户唯一的结构性优势是无杠杆+资金周期长，把它兑现的工具是宽基指数定投：横盘阴跌区间定期不定额分批建仓，越跌买得越从容——但前提只有一条：下跌有现金；满仓的人连定投的资格都没有。

## ② 素材引文逐字+出处（源: doubao/raw_日常号_补爬_2026-09-09/38434976035703810.jsonl idx=0，奇衡DK 体系笔记，第三方框架，行文用"有一套体系"引述视角）
- "UBW（无限剑制）——指数定投底仓策略（左侧核心工具）。适用标的：宽基ETF（科创50、沪深30、中证500），禁止个股使用。"
- "操作模式：市场长期横盘、持续阴跌区间，定期不定额分批建仓，平滑左侧下跌风险。"
- "底层逻辑：散户最大优势是无杠杆、资金周期长，利用持续定投摊薄成本，对抗庄家短期资金冲击。"
- "核心底层规则：下跌有现金是一切前提。全文高频金句：股市大跌时手里无现金，再多理论毫无意义；所有操作预留充足现金，拒绝满仓梭哈。"
- "金字塔分批建仓（恐慌逆市工具）：市场系统性暴跌（2020年初），正金字塔加仓：越跌分批小幅加，不一次性抄底，规避落刀风险，等待抛盘充分释放。"
- "长短仓分离（指数底仓+个股波段仓）：赛道分散+长短仓分离，单一个股仓位严格受限。"
