# brief — rotation-campaign《一轮牛熊的行军路线》

## ① 想法一句话
仓位决定买什么之前，先有一张行军图：一轮牛熊不是一次决策，是一串有先后次序的战役——每一步换什么板块、凭什么切换，切换必须基本面拐点和情绪冷热双验证，缺一个都不动。

- "四渡赤水战略：一渡赤水 2019 创业板；二渡赤水 2020 低估值蓝筹；三渡赤水 2021 科创（子午谷奇袭）；渭水对峙 2021 下半年收缩观望；白马之战 2022-23 高股息低吸；楼船夜渡 资源股波段。"
- "板块切换须基本面拐点+情绪冷热双验证，缺一不动。"
- "人多的地方不去；学会空仓（2021 下半年、2023 上半年休假减仓）。"（只作渭水对峙的注脚，不展开——空仓心性归姊妹篇）

## ④ 八法选法
立（牛熊=一串战役的行军图）+ 例（六阶段即骨架案例，只用语料年份与板块，不加新例）+ 破（倒放录像论是主破，须破得硬）。

## ⑤ 五气配比
断 4（双验证条款、缺一不动）+ 察 4（六阶段每段只给年份+板块+一句为什么，不展开行情复盘）+ 怀 3（R2/R4 两回合）+ 悯 1（只一句：满仓的人没有行军图，只有希望）+ 谐 0。

## ⑥ 形状
问句开场（同一轮牛市，为什么有人换对了三次，有人一次没换还站错了边？）；四节：一轮牛熊是一串战役 / 六个阶段的行军图（清单式，克制） / 倒放录像论与双验证 / 代价与适用边界；收口一句。800+ 汉字，短句为体。

## ⑦ 不适用边界
- 六阶段只用语料原文的年份+板块名，不补充任何语料外的行情数字、涨跌幅、个股。
- 不荐股不给当下判断（2026 该站哪一步，不写）。
- 第三方体系引述视角，不冒充站长自创，不点名。
- 与 narrative-rotation 分工（查重已做）：那篇讲叙事优先级轴（市场先信什么后信什么），本篇讲板块资金作战轴（每一步打哪个战场、凭什么切换）；两篇互不重复对方清单，本篇不引入叙事轴术语。
- 与 survive-the-cycle 分工：那是生存原则清单，本篇是进攻路线；渭水对峙只作空仓注脚，心性不展开（归 sit-out-in-cash）。
- 与 four-nested-cycles / cycle-formula 分工：那是周期驱动分层，本篇是板块轮动执行，不重复债务/情绪/结构三层框架。
