## ③ 对手戏回合表（反方无人称）
1. 开篇：一家几乎不做广告的公司，logo 却挂在商场最贵的位置；一屋子设计师，名字却从不出现在吊牌上——亮与藏，各有各的账。
2. 反方一（有人说）：不砸广告是抠门，品牌迟早吃亏 → 驳：曝光没有省，只是换了科目——同行把钱付给媒体，Zara 把钱付给地段；logo 立在人流最密的转角，门店本身就是广告位，还能顺带产出新闻，媒体替它免费写。曝光预算一分没少花，只是花在了不折旧的地方。
3. 反方二（也有人说）：设计师不署名是对创作者的漠视，好设计不该匿名 → 接一半：对创作者个人，署名是荣耀，这话成立。再驳：在诉讼名单越拉越长的处境里，署名的另一头是被告席——名字一旦挂出去，设计语言就成了可指认的证物；匿名不是姿态，是风险定价：曝光的收益归店铺，诉讼的风险留设计线，两本账不许混。
4. 反方三（还有人说）：这是掩耳盗铃，牌子照样被起诉 → 收：对，藏名字挡不住诉状——匿名从来不是免责手段，它降低的是把具体的人钉在具体的设计上、让官司从公司层面烧到个人层面的二次成本；风险栏没有清零，只是没有放大。
5. 收口：评判任何一家公司的招摇与沉默之前，先问亮出来的是什么科目、藏起来的是什么科目——预算只有一份，科目各有价目；把两本账读反了，就会把商业策略看成性格缺陷，或把风险控制看成道德瑕疵。
