# brief：slow-the-hands（第 71 篇）

## ① 想法一句话
投顾卖的不是收益，是替人管住那只频繁交易的手——多数人亏钱不在选错，在换手。

## ② 素材引文（语料 38435110387364610 §5.3，拆解 digest 逐字）
1. 「他认为基金投顾的本质不是帮投资者赚大钱，而是帮投资者降低换手率，管住频繁交易的手（第114篇）。」
2. 「大多数投资者亏损的根源，不是选的基金不好，而是频繁买卖、追涨杀跌，基金投顾的最大价值，就是帮投资者克服这些劣根性。」
3. 散户四大劣根性清单：「第一是短视，只想赚快钱，追涨杀跌，没有耐心等待价值回归；第二是盲从，喜欢听消息、跟大V，自己不做研究；第三是过度自信，涨了就觉得自己是股神，跌了就怪市场、怪政策；第四是盈亏不分，把浮盈当成自己的钱，舍不得卖，最后又亏回去，把浮亏当成"只要不卖就不是亏损"，最终深套。」
4. 「荐股友尽图」故事已被 bear-shouters 使用——本篇禁用该案例与"同甘不能共苦"句。

## ③ 对手戏回合表（3 回合）
| 回合 | 反方最强版 | 我方接法 |
|---|---|---|
| 1 | 我自己拿着就行，凭什么付钱请人拦着自己的手 | 管不住的手恰好不自知：问题不在懂不懂，在每次波动都重新做一遍决定 |
| 2 | 换手率高才灵活，死拿是懒惰，凭什么频繁交易是错 | 体系不反对动作，反对没有坐标的动作：每一次进出都该答得出理由 |
| 3 | 亏了怪基金，换一只就是了，投顾也就是个销售 | 换基金正是那只手的一部分：账户的问题跟着人走，不跟着产品走 |
（双方原话取自语料对大众共识的批判段）

## ④ 八法选 1-3
问句推进（判断收口）+ 察（盯手不看盘）+ 悯（一句：每只基金都拿过好收益、每次都卖在收益前面的人）。

## ⑤ 五气配比
断 3 · 怀 3 · 察 4 · 悯 1。

## ⑥ 形状
问句开场（账亏损，换掉的是产品还是手）→ 手的病历（四大劣根性）→ 投顾的真实账（降换手=替你少做决定）→ 三个质疑 → 悯一句 → 收口：管住手不是保守，是这套体系里最贵的服务。

## ⑦ 不适用边界
- 与 bear-shouters 划界：那边讲唱空者与盲从，本篇不讲唱空，劣根性清单只展开"盈亏不分/过度自信"两面，且禁用友尽图案例与"同甘不能共苦"句；
- 与 quant-desymbolization 划界：量化换手是工厂的精密动作，散户不可模仿——那边讲量化，这边讲散户的手；
- 与 art-of-selling 划界：卖出是手艺有标准，本篇讲的是没有标准时的乱动；
- 不提任何基金/投顾产品名，不构成投顾推荐，不写收益承诺。
