# brief — speculation-line《投机的门》

## ① 想法一句话
投机和投资的区别不在持有时长，在于锚：投机追题材、赌短期资金炒作，赌的是下一个人出更高价；投资锚定长期不变的商业模式、现金流和安全边际，赚的是均值回归。前者的门对普通人关着——不是道德关着，是胜率结构关着。

## ② 素材引文逐字+出处（源: 38434976035703810.jsonl idx=0，奇衡DK 体系笔记，第三方框架，"有一套体系"引述视角）
- "区分投机与投资边界：投机：追逐题材、无基本面支撑，赌短期资金炒作；投资：锚定长期不变商业模式、现金流、安全边际，依靠格雷厄姆均值回归获利。"
- "原文态度：投机游戏普通人不可参与，心智、耐性不足者必然亏损。"
- "利弗莫尔《股票作手回忆录》（市场情绪、对手盘逻辑）"（注：体系把这本书列为必修课——可用一笔划界：研究情绪对手盘是认知，把身家押上去做对手盘是另一回事，须小心处理不矛盾）

## ④ 八法选法
立（区别在收益从哪来，不在持有时长）+ 破（精英话术论为主破）+ 悯（一句）。

## ⑤ 五气配比
断 4（普通人不可参与，不缓和）+ 察 3（最后一棒/均值回归的结构拆解）+ 怀 3（R2/R4）+ 悯 1（只一句：门上没有告示，亏掉的钱就是告示）+ 谐 0。

## ⑥ 形状
问句开场（拿三天和拿十年，差的是时间还是别的什么？）；四节：锚定什么决定是什么 / 最后一棒与均值回归 / 精英话术论怎么接 / 对手盘研究的边界；收口一句。800+ 汉字，短句为体。

## ⑦ 不适用边界
- 不举例具体题材股、不给当下市场判断、不荐股。
- 第三方体系引述视角，不冒充站长自创，不点名。
- 与 macau-casino-fallacy 分工：那是博彩产业正当性的立场篇，本篇是投机/投资的执行边界，两篇不互相引用、不重复赌桌意象。
- 与 know-your-opponent 分工：本篇 R4 只做划界一笔，不重述对手研究内容。
- 与 hold-is-buy / easy-money 等篇分工：不重复"持有即买入""快钱"的既有论点，本篇只讲投机/投资的判定线。
- 避开"买的不是X是Y"句式（上轮留观项）——"锚定什么决定是什么"口径替代。
