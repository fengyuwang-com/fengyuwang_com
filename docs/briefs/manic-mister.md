# brief：manic-mister（第 70 篇）

## ① 想法一句话
有效市场只是教科书的假设，真实的市场先生是躁郁症患者——市场不理性不是缺陷，是长期收益的全部来源。

## ② 素材引文（语料 38435110387364610 §5.1，拆解 digest 逐字）
1. 「有效市场只是教科书上的假设，现实中的市场先生是一个情绪极不稳定的躁郁症患者，时而过度乐观，时而过度悲观，报价经常离谱得可笑（第119篇）。」
2. 「同一家公司，基本面没有本质变化，市值可以在一年里翻倍，再跌回原点。变化的不是公司，而是市场先生的情绪。」
3. 「新能源车、白酒的案例也同样如此：行业的基本面不会在几个月内发生天翻地覆的变化，但股价可以暴涨暴跌，本质都是市场先生的情绪在摆动。」
4. 「正因为市场是无效的，才会出现价格与价值的错配，才会有价值投资的机会。如果市场永远有效，价格永远等于价值，那投资者就没有任何超额收益可言。所以，市场的不理性、不变的人性弱点，恰恰是投资者长期盈利的基础。」
授权意象：躁郁症患者（brief ② 授权，可作单次核心比喻）。

## ③ 对手戏回合表（3 回合）
| 回合 | 反方最强版 | 我方接法 |
|---|---|---|
| 1 | 现在市场机构化了、定价高效了，市场先生早就治好了病 | 机构化了情绪还在，只是搬进了更大的房间；错配从个股搬到了板块 |
| 2 | 无效市场是机会，也是陷阱：你说它疯，怎么知道它这次不是对的基本面重定价 | 接法与 verify-not-forecast 同源：不猜这次疯不疯，只盯不变资产和坐标，等市场先表态 |
| 3 | 既然市场长期有效、短期无效，拿着不动等回归就行，研究情绪多余 | 短期无效正是买入的窗口，长期回归是兑现的通道——不研究情绪的人连窗口开着都不知道 |
（双方原话取自语料对有效市场教条与大众共识的批判段）

## ④ 八法选 1-3
问句推进（判断收口）+ 破（教科书假设 vs 真实报价）+ 悯（一句：把先生的报价当成先生人格的人）。

## ⑤ 五气配比
断 3 · 怀 3 · 察 4 · 悯 1。

## ⑥ 形状
问句开场（同一家公司，一年翻倍再跌回原点，公司变了什么）→ 先生病历（躁狂相/抑郁相/报价离谱）→ 无效=错配=机会的传导 → 三个质疑 → 悯一句 → 收口：治好市场的病，也就治死了收益。

## ⑦ 不适用边界
- 与 buy-diversiveness 划界：那边读人群的意见分布（分歧/共识），这边读市场先生本人的情绪状态；
- 与 cost-to-zero/sit-out-in-cash 划界：操作层归彼篇，这边只立"无效是收益之源"这一条世界观；
- 与 priced-in-new-york/money-life-cycle 划界：宏观传导归彼篇；
- 新能源、白酒只作行业级一笔，不提个股、不写当下判断；翻倍回原点不挂任何具体公司。
