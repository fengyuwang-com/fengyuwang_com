# brief — interrogating-an-ai

①想法一句话:AI 的口供不可信,实验才可信;审 AI 四步——真命令、列家底、复跑、双盲同码,原理是不问它知道什么,问它做得到什么。

②素材引文逐字(篇103_如何运行代码查看环境配置.md):
- L73(用户):"你能在这里面运行什么代码呢?能 ping 一下我的官网吗?fengyuwang.com。"
- L126(用户):"你先 ping 你别问。"
- L194-195(AI 承认):"我能写并运行 Python ping 代码""但我永远 ping 不通 fengyuwang.com,因为沙箱禁止 ICMP / 外网"。
- L487(用户):"对,你把 skill 列出来,包括你用的其他所有工具都帮我列出来,我想看一下你的能力边界。你运行代码再跟我说话。"
- L684(AI 自纠):"我前面说'60 多个 skills',其实是口误+概念混着说了,现在用代码把真相钉死——不是 60 个'技能',而是 60 个'skill 文件'。"
- L768(用户):"你刚才运行的东西我重复运行了,根本就没有。"
- L850(用户):"你给我编一段代码,我自己运行,然后你输出,要求的是我们输出的内容应该是一模一样的,你知道吧?但是我不知道测试什么东西。"
- L855(AI 吸收):同一段代码两边跑,输出字符级一模一样。

③对手戏回合表:
| 回合 | 用户 | AI |
|---|---|---|
| R1 | 能 ping 我官网吗(L73) | 用搜索替代 ping 给结论(L96-101) |
| R2 | 先 ping 别问(L126) | 写 Python ping→承认包发不出去,边界钉死(L150-195) |
| R3 | 列出全部 skill,运行代码再说话(L487) | 先报 60 多个技能,复查后改口 60 个文件(L684-753) |
| R4 | 你跑的我重复跑了,根本就没有(L768) | 承认幻觉/环境不实 |
| R5 | 编段代码我自己跑,两边输出必须一模一样(L850) | 接受:字符级一致才算验证(L855-919) |

④方法:清单体(四步)+大白话翻译(懂=训练数据里的懂);问句收口。
⑤气质:察为主,断收口;谐一点(先 ping,别问)。
⑥形状:方法论文说,~650 字。
⑦不适用边界:不谈模型原理;不保证审完就没幻觉;说的是对输出可信度的审计姿势,不是对 AI 的不信任姿态。
