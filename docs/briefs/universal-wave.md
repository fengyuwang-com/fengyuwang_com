# brief — universal-wave《浪型看土壤》

## ① 想法一句话
浪型不是普适真理，是市场的土壤长出来的——传统波浪理论适配股票供给稀缺的卖方市场，在供给充足的买方市场里失效；后者要换一套四段结构（底部箱体、主升、二次反弹、主跌）来看大周期。

- "自创普适浪识别底部箱体、主升、二次反弹、主跌四段结构，专门用于指数、板块大周期判断。"
- "不预测市场，只验证市场：拒绝主观预判顶部/底部，等待信号再操作。"（作背景：浪型是验证工具不是预言书）

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【玄学论】"数浪就是玄学，同样的走势怎么数都能数出想要的浪，改浪型只是换一套更好看的玄学。"——接法：玄学的问题不在浪，在把浪当预言；这套四段结构的使用方式是事后核对——底部箱体、主升、二次反弹、主跌，每一段都有可观察的边界，数错就认，不靠改口圆场。
2. 【水土不服反向论】"工具该放之四海，为一地市场特制一套浪型，是削足适履地迁就局部。"——接法：浪型的底层是筹码供给结构——供给稀缺的卖方市场和供给充足的买方市场，本来就是两种博弈，工具跟着结构走不是迁就，是校准；拿错土壤的尺子量树，错的是尺子不是树。
3. 【用处怀疑论】"就算分清四段又如何，判断指数板块大周期，对选股没有直接用处。"——接法：大周期的位置决定弹性仓的方向和底仓的加仓节奏——体系是先指数板块、再精选个股，浪型管的就是第一层；跳过第一层直接选股，赚指数亏个股的老账已经算过。

立（浪型由土壤决定）、破（玄学论）、成（四段结构可核对）。
