# brief — tollbooth-platform

①想法一句话:价值投资就是投平台——壁垒不在路修得平不平,在"只有这一条路+收费站";收费的是暂时还是永久,取决于替代意愿。

②素材引文逐字:
- 篇012 L7082(用户):"你路做的平不平都没事,你路坑坑洼洼的,只要你这路上修收费站,人家只有你一条路要走,他反正还得给你收费站交钱。"
- notes A1.3(篇012 标准表述):"历史上没有什么东西是一直火的,除非你是掌握了那个平台的东西。我觉得价值投资的话,其实就是投平台。苹果公司掌握了手机的平台,可口可乐掌握了饮料的平台。Visa Master 掌握了支付的平台……没有什么真的投那个什么这一段时间火的那个 IP。"
- notes A1.3(篇001):中国电信="有了自己网的 AWS";CN2 海缆=token 出海的收费站,"中国想把电费便宜卖给外国,你不可能卖商品,你就卖给外国 AI 推理"。
- 篇012 L6707(AI 吸收):腾讯是"AI 时代的收费站",不是"AI 时代的赛车"。
- notes A1.3(篇012):"NV 难替代,但大家都想替代。微信难替代,没人敢替代。"
