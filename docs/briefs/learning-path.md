# brief — learning-path《四本书，一个顺序》

## ① 想法一句话
学投资不是收集知识点，是按依赖顺序装一套操作系统：四门核心课按序读（价值根基→情绪对手盘→风控周期→波段节奏→止盈离场），两门选修补产业与低估值思路，其余一切碎片化输入——短视频、消息、荐股——都替代不了这个闭环。

## ② 素材引文逐字+出处（源: 38434976035703810.jsonl idx=0，奇衡DK 体系笔记，第三方框架，"有一套体系"引述视角）
- "学习路径：系统化经典闭环（4+1+2课程体系）。核心阅读顺序，构建完整交易认知，拒绝碎片化短视频、消息炒股。"
- "格雷厄姆《证券分析》（底层价值根基）；利弗莫尔《股票作手回忆录》（市场情绪、对手盘逻辑）；《专业投机原理》风控、周期；《以短线交易秘诀为生》波段节奏；《卖出的艺术》止盈离场（4门核心课=4）。"
- "补充：彼得林奇、约翰聂夫（+2），产业调研、低估值红利思路。"
- "长期终身学习：市场规则、产业持续迭代，不存在一劳永逸炒股方法。"（心性规则第 4 条，作收口支撑）

## ③ 对手戏回合表（承重 4 回合）
| # | 谁 | 内容 | 出处 |
|---|---|---|---|
| R1 | 散户直觉 | 读书不如实盘，知识在盘子里学得最快；书是上世纪的，早过时了 | "拒绝碎片化"的对面 |
| R2 | 反方最强版 | 现在要信息要工具都即时可得，短视频三分钟讲透一个概念，凭什么要花几个月啃五十年前的书 | "拒绝碎片化短视频、消息炒股"的对面最强版 |
| R3 | 体系回应 | 碎片给的是结论，经典给的是推导——三分钟讲得透一个概念，讲不透概念从哪来；书单是有顺序的：先有估值根基，才读得懂情绪对手盘，才有资格谈风控和离场，顺序错了每一本都白读 | 4+1+2 依赖顺序 |
| R4 | 再反方 | 那读完就一劳永逸了吗 | 读不完——市场规则、产业持续迭代，这套路径给的是底盘不是终点，之后靠终身学习续命；不存在一劳永逸的方法 |

## ④ 八法选法
立（认知有依赖顺序，像装操作系统）+ 破（碎片效率论为主破）+ 例（五本书各给一句它在闭环里的位置，不加书外内容）。

## ⑤ 五气配比
断 4（拒绝碎片化，顺序不能乱）+ 察 3（五本书各管哪一课、为什么这个顺序）+ 怀 3（R1/R2/R4）+ 悯 1（只一句：跳着读的人，缺的那一课总在亏掉之后才补上）+ 谐 0。

## ⑥ 形状
问句开场（同样二十年书龄的两个人，差距是从哪一步拉开的？）；四节：学的是系统不是知识点 / 五门课的顺序（4+1+2 清单式，克制） / 碎片为什么替代不了 / 底盘与终身学习；收口一句。800+ 汉字，短句为体。

## ⑦ 不适用边界
- 五本书只给书名+它在闭环中的位置，不复述任何一本书的内容、不给读书笔记。
- 不编造站长自己的读书经历、不加书外书；彼得林奇/约翰聂夫只作"+2 选修"一笔，不展开。
- 第三方体系引述视角，不冒充站长自创，不点名。
- 与 art-of-selling 分工：那篇讲卖出纪律内容本身，本篇只把它当作闭环里的第 4 门课，不复述其论点。
- 与 know-your-opponent 分工：那篇讲对手研究，本篇只把《作手回忆录》列为第 2 门课的名称，不展开其观点。
- 避开"买的不是X是Y"句式（上轮审读留观项）。
