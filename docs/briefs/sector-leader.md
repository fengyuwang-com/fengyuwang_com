# brief — sector-leader《行情只认领头羊》

## ① 想法一句话
一轮行情里，行业周期决定个股七成涨跌，而板块内部真正值得做的只有领头羊——调整时跌得少、反弹时起得快的那个；跟风杂毛的便宜，是流动性差、弹性弱的另一种写法。

## ② 素材引文逐字+出处（源: doubao/raw_日常号_补爬_2026-09-09/38434986634566146.jsonl 基于 1911 篇雪球原文，第三方框架，行文用"有一套体系"引述视角）
- "先指数板块，再精选个股：行业周期决定个股70%涨跌，个股基本面只是增量；先判断赛道景气，再选股，避免赚指数亏个股。"
- "板块领头羊判断方法：一轮行情核心辨识度龙头，板块调整时跌幅更小、反弹更快；只做领头羊，不做跟风杂毛，规避流动性差、弹性弱个股。"
- "基本面研究 KISS 极简原则：核心不变资产三句话讲清，逻辑越简单越可靠"（可作领头羊辨识的旁证一笔，不展开）。

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【补涨论】"龙头涨完了，轮到低位跟风股补涨，便宜才是安全垫。"——接法：补涨是事后叙事，事前没有时间表；语料写死只做领头羊、不做跟风杂毛——杂毛的便宜背后是流动性与弹性两笔折价，行情退潮时最先失去买盘的正是它们。
2. 【龙头太贵论】"领头羊人人盯着，溢价都透支了，买它等于替别人的共识买单。"——接法：贵不贵是估值坐标的事，本篇不展开；但"共识"一词恰好说反了——领头羊是行情里辨识度最高的核心，调整时跌幅更小、反弹更快是可观察的行为，不是猜测；怕贵的解法是等坐标，不是去买没人要的杂毛。
3. 【研究平权论】"认真研究下去，杂毛里也能挖出下一个龙头；大家都盯着龙头，超额才轮不到看杂毛的人。"——接法：行业周期决定七成涨跌——把研究力气花在赛道内的第三名、第四名身上，赌的是那三成里的奇迹；判断景气在先、选择标的在后，顺序不可逆，杂毛里的奇迹属于运气，不属于方法。

## ④ 八法选 1-3
立（七成归板块、辨识度看行为）、破（补涨论）、断（只做领头羊的纪律）。

## ⑥ 形状
开场问（同一个板块，为什么有人赚指数亏个股）→ 立（七成归板块，剩下三成里选头）→ 对手三回合 → 收口（跟风省下的功课，最后都交还给市场，一句收）。

## ⑦ 不适用边界

- 与 rotation-campaign / narrative-rotation 分工：那两篇讲板块轮动的作战图与叙事轴，本篇不写轮动时点。
- 与 weeds-and-flowers 分工：拔野草浇鲜花是仓位动作，本篇是标的甄别，不重复。
- 估值贵贱归 coordinate-principle，一句带过不展开。
