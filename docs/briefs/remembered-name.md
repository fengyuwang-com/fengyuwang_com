# brief — remembered-name《被记住名字的那一刻》

## ① 想法一句话
记住名字是服务的最小单位——酒保看见熟客就开调马提尼，售货机认出会员报出名字；技术没发明什么，只是把"雷先生来了"规模化。

## ② 素材引文（逐字+出处，≥3）
1. "如果你是露得清的会员，当你走近这台自动售货机时，它会在这里显示你的名字。它会说：'欢迎回来，吉恩。你上次来的时候购买了这个产品。你想再次订购吗？'然后你只要说是……它已经有你的支付信息了，商品就会从自动售货机里出来。" — Customer Service Automation_240130.md L45（美国祛痘品牌在日本推面部识别售货机；品牌中文名转写有噪声，正文只写"一家美国祛痘品牌"）
2. "所以我妈妈过去所践行的理念一致，当你的名字被记住时，人们总会感觉更好。" — 同上 L45 附近（讲师自述源此）
3. "每个星期五晚上，我都会去一家名为'拉皮兹午餐'的餐厅。我一走进餐厅，每个人都会说：'雷先生，你好吗？'他们马上就开始给我调马提尼酒，我甚至都不用告诉他们。人们喜欢这样的服务，这会让你再次光顾。" — 同上 L70
4. "所以我们负责他们在日本的所有市场营销工作……日本的人均自动售货机数量比世界上任何其他国家都多。" — 同上 L40（选址逻辑：把机器放进最习惯无人售货的市场，再用识别还原"有人认识你"）

## ③ 对手戏回合表（3-6 承重回合）
- R1 反方「新鲜感衰减论」：机器叫一次名字很惊喜，叫一百次就腻了，噱头撑不久。→ 正面接：腻的不是被记住，是被方式记住——只会在进门时喊一声名字的，确实会腻；酒馆十五年不腻，因为它记的是偏好不是标签（连"不用告诉"都要调什么酒都记得）。名字只是入口，记住的深度决定保质期。
- R2 反方「成本倒挂论」：为了一个问候装识别系统，账算不过来。→ 接：这笔账买的不算问候——识别直接驱动复购动作（"你想再次订购吗"+支付信息已在），问候是表象，省掉的下单阻力是真金白银；讲师自述"非常非常成功"。酒馆老板的记性不要钱，机器的记性按台折旧，机制相同，账本不同。
- R3 反方「机器廉价论」：报名字是程序打印的，酒馆的人情它学不来。→ 接：人情从来不在声带上，在内容里——"雷先生"后面跟着的是不用开口的马提尼；机器要是只打印名字，确实廉价，可机器把"上次买的、这次要的"一起记住了，内容并不比酒保薄。客户分不清也不必分清声带与程序，分得清的是被记住与被当作陌生人。
- R4 反方「冷市场论」：日本人人排队自购，没人需要被认识，这案例换地方就死。→ 接：选址恰恰是反证——讲师团队把机器放进"人均售货机最多"的市场，是要在最冷的自助场景里补回最热的那句话；越是没人认识你的地方，"欢迎回来"越值钱。案例没有换地方就死，是换地方才成立的。
