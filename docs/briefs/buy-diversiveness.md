# brief — buy-diversiveness《买分歧，卖共识》

## ① 想法一句话
超额收益的进出时点不藏在价格里，藏在人群的意见分布里：分歧最大、悲观弥漫时买，共识形成、人人看好时卖——市场无效性给的错配价，要用大众认知的偏差去收。

## ② 素材引文逐字+出处（源: 38435110387364610.jsonl，奇衡DK 投资思想梳理，第三方框架，"有一套体系"引述视角）
- "提出'买分歧，卖共识'的逆向投资策略，以潍柴动力、房地产等案例，说明在分歧大时买入，共识形成时卖出，还认为市场风格之争意味着行情未结束。"
- "'买分歧，卖共识'利用大众认知偏差，分歧大时悲观情绪释放，价格低于价值，安全边际高；共识强时乐观情绪透支，价格高于价值，风险大，是息价原则在市场行为的体现。"
- "市场大众常犯把周期上行阶段当永恒增长的错误……因人性不变，大众易健忘，认识周期不变性与大众记忆短暂性，能跳出'追涨杀跌'怪圈。"
- "基于市场无效性，指出价格与价值错配带来价值投资机会。"
- （案例仅授权"潍柴动力、房地产"两名词，不给年份涨幅细节）

## ④ 八法选法
立（收益藏在意见分布里）+ 破（"共识=对"为主破）+ 例（潍柴/房地产一笔，无细节）。

## ⑤ 五气配比
断 4（进出时点由意见分布定，不含糊）+ 察 3（分歧/共识各自的价格含义）+ 怀 3（R2/R4）+ 悯 1（只一句：骂声最响的地方，价签往往最便宜）+ 谐 0。

## ⑥ 形状
问句开场（一笔好交易的信号，怎么会在人人都说坏的时候？）；四节：价格里装着意见 / 分歧与共识各自标价 / "共识=对"怎么接 / 大众会不会学乖；收口一句。800+ 汉字，短句为体。
