# Brief — survive-the-cycle《周期里，先活下来》

## 语料出处
doubao 补爬《穿越周期系列内容规划》_651714，第12集框架（idx=10 附近豆包整理，站长逐集审定）+ idx=11 站长口述（长周期篡改认知）。

## ① 想法一句话
不被周期收割的原则只有几条，而且互相配套：人多的地方不去，底部不割肉，现金流为王，分散搭配，最后一条是个人能力才是穿越所有周期的资产。

## ② 素材引文逐字 + 出处（≥3）
1. 「不要在泡沫顶峰追热点：永远记住'人多的地方不要去'，当你身边所有人都在讨论AI的时候，大概率已经是泡沫中后期。」（_651714 第12集框架，站长审定）
2. 「不要在周期底部割肉：被遗忘的赛道里，往往藏着下一轮周期的机会，前提是资产本身不会消失。」（同上）
3. 「现金流为王：周期里活下去比赚快钱更重要，保留足够的现金，才能在底部捡到便宜的筹码。」（同上）
4. 「分散配置：不要all in任何一个周期赛道，不同周期阶段的资产做搭配，才能平滑波动。」（同上）
5. 「提升自身的抗周期能力：个人能力是穿越所有周期的核心资产，比任何投资都重要。」（同上）
6. 「房地产会是个周期是如此的长，而且它的给人的印象是如此的深，以至于它让人们认为，这个不是一个偶然现象……这个是个必然现象。」（站长原话，_651714 idx=11）
7. 「我们做穿越周期系列，不是为了预测精准的顶和底，而是为了明白：我们当下经历的所有狂热、迷茫、悲观，都不是第一次发生，也不会是最后一次。」（_651714 第13集，站长审定）

## ④ 八法选 1-3
数字去向表（五条原则按「收割发生在哪一步」排序：顶部追高/底部割肉/中途断粮/单点押注/本钱错配）+ 边界自划（资产本身会消失的不适用）+ 问句收口。

## ⑤ 五气配比
怀为主（这是写给普通人的行动指南），断为辅（五条是硬原则不留余地），悯一句（底部割肉的人），察配机制，谐点一笔。

## ⑥ 形状
清单体+机制解说：五条各一小节，每条先给反例（收割怎么发生）再给原则；前置一节讲长周期为何篡改认知（地产案例）。

## ⑦ 不适用边界
- 「底部不割肉」有一条硬前提：资产本身不会消失（语料原文自带）。消失型资产（归零币、骗局）不在保护范围，必须写明。
- 本文是原则不是操作信号：不回答任何具体买卖时点（位置判断已有 top-bottom-signals，估值位置已有 over-under-now，不重复）。
- 白酒叙事细节已被 over-under-now、baijiu-dual-market 使用，本文禁再用白酒案例；地产只用「周期长到被当成必然」这一个意象。
