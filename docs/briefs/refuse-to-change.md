# brief — refuse-to-change《变的时候他不想变，他就结束了》(篇047)

## ① 想法一句话
两个同名的人隔着九百年死于同一种病：变的时候不想变；但想变的也会死（姿势/时机），真正的分水岭是「守成账」压过了「变法账」。
