# brief — diversify-net《分散，是为了网住大鱼》

## ① 想法一句话
分散的本土化用法和学院派不是一回事：学院派分散是降低波动（数学题），这套体系的分散是主动逆向撒网、网住低估的大鱼（打鱼的事）——配合分层规则（赛道分散+长短仓分离+单票限额），黑天鹅来了只伤皮毛。

- "组合分散规则（格雷厄姆分散本土化）：格雷厄姆分散是网住低估大鱼（主动逆向挖掘冷门），而非学院派单纯降低波动。"
- "分层分散：赛道分散（消费+制造+医药+金融）、长短仓分离（指数底仓+个股波段仓），单一个股仓位严格受限，避免黑天鹅（多氟多、东阿短期暴雷仅小幅影响组合）。"
- "核心底层规则：下跌有现金是一切前提；拒绝满仓梭哈。"（作前提一笔，不展开——cost-to-zero/ubw 已用）
