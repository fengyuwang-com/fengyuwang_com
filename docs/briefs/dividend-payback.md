# brief — dividend-payback

②素材引文逐字:
- notes A1.6(篇086):"你看的是股价,我看的是股息,我是要靠股息回本的。"
- 篇086 L10(AI 吸收):苏泊尔现价 40.10,PE(TTM)15.85,股息率 6.53%,"高股息、低估值"典型状态。
