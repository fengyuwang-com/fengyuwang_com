# brief：position-cap（第 69 篇）

## ① 想法一句话
个股止损人人挂在嘴上，总仓位的止损没人做——跌得越深仓位上限越低，这条反直觉的规则是账户的空气囊。

## ② 素材引文（语料 38434986634566146 第三部分 4，拆解 digest 逐字）
1. 「上证2638下方：总仓位上限30%，多看少动，只拿极小跟踪仓，绝不重仓做多；有效站稳2638：依托该支撑，回调加仓，打开弹性仓位。」（2018-2019 每篇专栏开篇硬性仓位规则）
2. 「2638是市场消化全年悲观预期的估值底部，下方无系统性吃饭行情，任何个股独立行情都极难持续。」（同上——上限的依据是系统性风险，不是点位预测）
3. 「严格执行顶层息价+点位规则……规避2018全年系统性下跌，大幅控制账户回撤。」（第十一部分案例 4）
4. 「主动放弃不确定的潜在利润，回避不可逆永久亏损。」（取舍原则——上限是取舍原则在总仓位上的落实）
授权数字：2638、30% 两处只作历史规则名词一笔，不展开点位分析。

## ③ 对手戏回合表（3 回合）
| 回合 | 反方最强版 | 我方接法 |
|---|---|---|
| 1 | 越跌越便宜，越便宜越该买，设上限是把便宜货挡在门外 | 上限挡的不是便宜，是"便宜之后还有系统性更便宜"；估值管买什么，上限管买多少，两把尺 |
| 2 | 点位上限是拍脑袋择时，明天就失效 | 接法与 verify-not-forecast 同源：上限挂在可证伪的位置上，跌破认错，站稳打开——是规则不是预测 |
| 3 | 个股止损就够了，组合跌是个股都跌，一个一个止就行 | 系统性下跌里个股止损是排队割肉：总仓位上限一刀切，省下的不是钱是执行难度 |
（双方原话取自语料对大众共识的批判段）

## ④ 八法选 1-3
问句推进（判断收口）+ 取舍（上限本质是主动放弃）+ 悯（一句：满仓扛过 2018 全年的人）。

## ⑤ 五气配比
断 3 · 怀 3 · 察 4 · 悯 1。

## ⑥ 形状
问句开场（账户有止损，账户本身有没有）→ 上限规则拆开（下方封顶/站稳打开/逐级上移）→ 依据是系统性风险不是预测 → 三个质疑 → 悯一句 → 收口：上限平时像浪费，出事那天是空气囊。

## ⑦ 不适用边界
- 与 base-position 划界：那边讲三笔钱各管各的纪律（仓内结构），这边讲总仓位对系统性风险封顶（仓外总量）；
- 与 top-bottom-signals 划界：那边讲十个信号定位位置感，这边不讲任何信号，只有一条事前写死的上限规则；
- 与 sit-out-in-cash 划界：空仓是看不懂时的判断，上限是看得懂时也执行的纪律；
- 2638/30% 只作历史名词一笔，不给任何当下指数点位判断，不荐股，不写当下仓位建议。
