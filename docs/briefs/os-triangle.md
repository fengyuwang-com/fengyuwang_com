# brief — os-triangle

①想法一句话:安全/自由/低认知负载构成消费级操作系统的不可能三角;macOS"都做到了"的真相是把认知负载转嫁给开发者;三角不会消失只会转移。

②素材引文逐字:
- notes B1(篇000,用户):"消费级操作系统的不可能三角:安全——意味着总要有人管控行为 / 自由——意味着系统不能(过多)管控用户行为 / 认知负载低——意味着用户难以管控自己的行为。这说法对吗?我觉得 macOS 都做到了。"
- notes B1(篇000):iOS 极度简单;macOS 极度复杂(开发者友好但违背认知负载低);安卓取巧但"完全不允许直接用可执行文件,一定要用虚拟机"。
- notes B1(篇000):完美手机 Linux 思想实验(兼容安卓/跑 Docker/充足权限)"怎么就没有了呢?"(此素材主用于 pc-no-android,此处备用)
