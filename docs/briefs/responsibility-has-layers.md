# Brief — responsibility-has-layers（第 37 轮）

## ① 主题与立场
社会责任不是捐款的同义词。联合国式的三层圆模型把责任分层：内圈是把生意本身做好——增长、产品、就业；中圈是在经营中对社会价值观的变化保持敏感——不污染、不把人当耗材；外圈才是主动改善社会环境。立场：一家公司按时发工资、养活一百万个家庭，这本身就是最重要的社会责任；捐得少不等于不负责，把第一层做好是资格，外圈是余力，顺序不能倒。

## ③ 回合表
1. 开篇：一家不捐款的公司，可能是最负责任的公司——前提是它的责任有分层。
2. 反方一：社会责任就是做慈善，捐款多少是唯一的尺子 → 驳：内圈才是地基——增长、产品、就业；按时发工资、让一百万个家庭有收入，这已经是社会拿到的好处；用捐款单否定经营本身，是把第三层当成了全部。
3. 反方二：那把生意做好就可以对其他一切闭眼 → 接一半再驳：第一层做好是资格，不是赦免——第二层要求经营本身对社会价值的变化保持敏感：不把废水留给河流，不把 996 留给员工；经济功能的行使方式本身就是责任的一部分。
4. 反方三：既然前两层就够，第三层是伪善的装饰 → 收：外圈不是装饰，是余力的去向；模型自己说了"不能指望每家都做到这一层"，但也没说做到前两层就有权嘲讽第三层；分层的意义不是豁免，是排序——地基没打完就盖屋顶是表演，打完地基再加盖是余力。
5. 收口：评判一家公司先看三层里它站在哪，再看它有没有谎报楼层；社会责任的账要按层记，混在一张捐款单里，谁都能作弊。
