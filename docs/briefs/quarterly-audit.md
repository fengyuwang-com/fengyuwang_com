# brief：quarterly-audit（第 67 篇）

## ① 想法一句话
年报、一季报窗口不是读业绩的窗口，是给判断年检的窗口——不变资产还在不在、估值坐标漂没漂，半年一次重新过秤。

## ② 素材引文（语料 38434986634566146 第八部分第 8 步 + 第三部分，拆解 digest 逐字）
1. 「定期复盘：年报、一季报窗口重新更新企业不变资产与估值坐标。」（第八部分实战闭环第 8 步）
2. 「宏观定调：读取无风险利率，判断股/债大类资产配比；产业筛选：……基本面筛查：提取各赛道"不变核心资产"，搭建三维估值坐标，计算安全边际。」（第八部分闭环前四步——复盘即闭环重跑，不是写总结）
3. 「全部指标可量化（利率、估值、均线、产能），不靠主观情绪、小道消息。」（第十部分优势 3——年检的对象是可量化指标，不是心情）
4. 「年报里只有过去，拐点在路上和货架上。」→ 此句已用于 field-research，本篇禁用（围墙外）。

## ③ 对手戏回合表（3 回合）
| 回合 | 反方最强版 | 我方接法 |
|---|---|---|
| 1 | 持有就好，复盘是短炒者的习惯——长线投资者一年看一次足够 | 复盘的对象不是股价是判断：不变资产被季报证伪的那天，不查账的人最后知道 |

| 3 | 判断错了再改也一样，何必按日历 | 按日历不是仪式感，是对冲确认偏误：没人主动翻自己看错的账 |
（双方原话取自语料对大众共识的批判段与原文纪律段）

## ④ 八法选 1-3
问句推进（判断收口）+ 取舍（不动也是结论）+ 悯（一句：年报季里装作没看见的人）。

## ⑤ 五气配比
断 3 · 怀 3 · 察 4 · 悯 1（怀=对"持有就好"与"反应过度"两边都拆）。

## ⑥ 形状
问句开场（上一次打开自己的判断是什么时候）→ 复盘检什么（不变资产三问）→ 坐标漂移检定 → 三个质疑回合 → 悯一句 → 判断收口：年检通过的人什么都不用做。

## ⑦ 不适用边界
- 不写业绩超预期/低于预期怎么交易（field-research、art-of-selling 已覆盖卖出侧）；
- 与 field-research 划界：那边讲财报之外的现场，这边讲财报窗口对既有判断的复核；
- 与 verify-not-forecast 划界：那边讲等市场表态的进场标准，这边讲已持判断的定期重估；
- 不给任何当下公司判断，不荐股；2638 及点位不出现。
