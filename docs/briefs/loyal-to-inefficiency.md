# Brief — loyal-to-inefficiency（第 37 轮）

## ① 主题与立场
忠诚是先发者最值钱的资产，也是用户最容易付错的一笔钱。网景 Navigator 曾是互联网的催化剂——没有它互联网只属于专业人士；它是先发者用忠诚筑起护城河的典范。但护城河的另一面：用户因为忠诚留在低效系统上，忠诚从资产变成枷锁。立场：忠诚本身没有错，错的是把忠诚当成不需要重新验证的决定；系统可以过时，忠诚不会自动跟着过时。

## ③ 回合表
1. 开篇：一个用惯的浏览器消失之后，忠诚去了哪里——先发者最值钱的遗产，也是用户最难退的货。
2. 反方一：忠诚是用户的美德，先发者赚忠诚天经地义 → 接：这半句成立——Netscape 把互联网从专业人士的工具做成公众的日用品，这份忠诚是它应得的报酬；培养忠诚确实是早期进入者最大的优势。
3. 反方二：那跟随者只要做得更好就能赢，忠诚不值一提 → 驳：忠诚的黏性超出产品逻辑——IE 出现后 Netscape 消失了，可用户的手指还停在旧习惯上；连明知它消失的人都在自嘲"这大概是个错误"，忠诚的惯性比它的理由活得久。
4. 反方三：这是用户愚蠢，与先发者无关 → 收：这正是先发策略的完整算式——先发者赚两笔钱，一笔是当期的市场，一笔是滞后的惯性；第二笔赚的就是用户重新验证的成本。忠诚没有错，错的是把它当成不需要年检的资产；系统会过时，忠诚不会自动跟着过时。
5. 收口：定期问一句——我还在为它付费的，是今天的它，还是当年的它；答案分不出来的时候，忠诚就变成了对低效系统的续费。
