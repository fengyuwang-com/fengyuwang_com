# brief — tonghuashun-paradox

①想法一句话:同花顺悖论——软件为了目标 A(赚钱),目标用户是非 A(亏钱的人),效果也是非 A;卖的不是工具是"正在赚钱"的剧本;整个金融业对散户长期是娱乐业。

②素材引文逐字:
- 篇012 L5081(用户):"同花顺这个软件只能给不赚钱的人用,我换句话说,我在同花顺上天天看到不赚钱的人在上面吐槽呢。上面骂娘。那这个事情挺有意思,就是说这个软件本身是为了目标 A,但是它的目标用户是非 A,它的效果实际上也是非 A,我靠,这这个事情有点反直觉啊。"
- 篇012 L4827(用户):"你要价值投资,你你最好啥软件都不要,就好像巴菲特他肯定没有同花顺,因为他连智能手机都没有,但是他每天就看那个报表,他就能研究出来。"
- 篇012 L5241(用户):"我觉得长期来看,整个金融业对于散户来说就是一个娱乐业。"
