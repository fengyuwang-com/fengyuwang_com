# brief — resistance-inside《想变的组织，死在想变上》

## ① 想法一句话
柯达的高层早就看见了数码相机的未来，还是差点死了——因为阻力从来不在董事会的判断里，在组织的技能结构里：八成员工是化学学位，没人愿意为电子项目加班；想让创新活下来，它就得是 CEO 的活。
