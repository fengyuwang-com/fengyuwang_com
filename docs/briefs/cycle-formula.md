# brief: cycle-formula 《周期不是一种力量，是三层》

## ① 一句话
一轮完整的牛熊不是单一原因推动的，是三层东西叠出来的：债务决定生死，情绪决定多疯，结构决定炒什么——把三层拆开，周期就不再玄学。
