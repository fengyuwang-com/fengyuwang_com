# brief — buy-then-work《买完，功课才开始》

## ① 想法一句话
买入不是终点，是开始交作业——持有不等于躺平，得立三把标尺定期校验：资产锚、业绩锚、行业拐点；长期不变的核心逻辑一旦破坏，无条件离场，不存在死拿到底的长期主义。

## ② 素材引文逐字+出处（源: private-AIExport/doubao/conversations_日常号_补爬_2026-09-09/梳理投资思想逻辑主线_738626.md，conv 38434990043738626，第三方框架，行文用"有一套体系"引述视角）
1. "买入不等于持有不动，建立动态跟踪标尺，分三类跟踪指标：1.资产锚跟踪……2.业绩锚跟踪……3.行业拐点跟踪。"
2. "企业股权激励解锁条件，每年扣非ROE、营收增速是否达标；底层逻辑：股权激励是管理层业绩最低承诺，未达标代表基本面逻辑破局。"
3. "一旦长期不变的核心逻辑被破坏，无条件减仓离场，不存在「死拿到底」的长期主义。"
4. "资产锚跟踪：隐蔽资产企业跟踪土地整备、拆迁、资产处置公告（中集）。"
5. "行业拐点跟踪：政策、资本开支、行业竞争格局变化（带量采购、5G资本支出、军购预算）。"

## ③ 对手戏回合表（反方为语料内真实最强版，无人称出场）
1. 【躺平赢家论】"真正的价值投资就是买入后关掉软件，十年不动，跟踪是投机者的焦虑。"——接法：跟踪的不是股价是逻辑——资产锚、业绩锚、拐点三把标尺量的是"当初买入的理由还在不在"；关掉软件关不掉行业变化，等打开时理由可能早没了。
2. 【卖出亏损论】"盯着业绩看，一年不达标就跑，那不把好公司都洗出去了？"——接法：标尺量的是扣非ROE、营收增速对股权激励解锁条件的达标情况——激励条件是管理层自己签字画押的最低承诺，承诺人都没做到，逻辑破局不是情绪波动；量的是承诺，不是季度心情。
3. 【长期主义免死论】"只要信仰长期主义，逻辑变了也该拿住，拿住才配得上复利。"——接法：长期主义的本金是"不变"，不变没了长期就是口号——核心逻辑被破坏时无条件离场，不存在死拿到底；复利的前提是每一次持有都有理由，理由没了，剩下的只是仓位。

## ⑦ 不适用边界
- 与 hold-is-buy 分工：那篇讲评级是产品（卖方立场），本篇讲自家的跟踪标尺，卖方一律不出现。
- 与 fundamentals-unchanged 分工：那篇讲区分永久受损与情绪砸盘（判断框架），本篇讲跟踪的具体工序（三标尺），"永久受损"概念只一笔引用不重述。
- 与 right-to-sell 分工：那篇讲止损是权利，本篇不展开止损技法；"无条件离场"只指逻辑破坏，不指价格止损。
- 与 good-company-good-stock 分工：那篇以激励价作价格锚（买入参考），本篇以解锁条件作业绩锚（持有校验），同一素材两个用途须划清。
