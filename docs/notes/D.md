### D1. 万物皆 Prompt 论【自创】(篇011)
- 原文:"Skill 也是一种 Prompt,包括那个设计也是一种 Prompt,包括我觉得其实法律也是一种 Prompt。所以其实所有的知识工作好像都是 Prompt engineering。"
- Prompt 资产的可反推性:"Prompt 能成为一家公司,比如自媒体的核心资产吗?……你如果知道你的 pose(产出)的话,你是可以反推那个 prompt 的。"——护城河存疑。
- 突围方案(自研五层 meta analysis):"你想到小红书只想到'家人们谁懂',这是最浅层;深一层是调动情感、激发购买、分享期望的生活;再深一层是关键词库、大数据向量库、语料库,加上情感的 layer、词语的 layer——meta analysis 之后,就有独特的工作流数据库。"
- 人机并行架构(他反复纠 AI 画图纠出来的):"这两个东西处于同一个 layer,人把关品牌的方向,机器把关 meta analysis。"再加双重循环:"交付完了,回过去研究战略,回过去研究内容。"
- 方法论商品化意识:"就好像华与华方法,方法得有一套东西在里面。你把方法特色写清楚——人机协作是一个特色,语言学分析、RAG 分析、向量分析也要体现在名字里面。"(最终命名讨论收敛为"元分析"直译:"为什么是 Meta 分析?不能直接说元分析呢?")

### D3. 内容生意 vs 编程生意【自创】(篇011)

### D4. 分块 vs 长上下文的 token 经济学【自创】(篇011)
- KV Cache 语义:"一句话前面一样,后面不一样,前面一样的部分还是可以命中缓存。"(触发条件=前缀一致)
- 成本结论:"提示词是 KV 缓存,基本上不要钱,1% 的价钱都不到。"
- 注意力稀疏论:"100 万字一下子输进去,它的注意力越来越稀疏。"
- 上下文干扰论:"红楼梦跟水浒传不相干,一起扔进大模型,就算能处理那个上下文,也会互相干扰,导致输出不准。"→分块处理的正当性。
- 计算实录:1 万段×100 字+每段 50 字提示词 vs 100 万字一次性,要求 AI 用 Python 重算(纠出 AI 用旧价格:"你这个搞错了,我们现在都五四时代了,你这个都是老皇帝")。

### D6. 自主可控正名论【自创,政治经济学】(篇021)

### D7. 记忆=供应商锁定论【自创】(篇128)
