### B1. 消费级操作系统不可能三角【自创】(篇000)
- 原文:"消费级操作系统的不可能三角:安全——意味着总要有人管控行为 / 自由——意味着系统不能(过多)管控用户行为 / 认知负载低——意味着用户难以管控自己的行为这说法对吗?我觉得 macOS 都做到了。"
- 展开:所有系统都在这三件事上做平衡;macOS 是"极度复杂"(开发者友好但违背认知负载低),iOS 是"极度简单";安卓取巧但"完全不允许直接用可执行文件,一定要用虚拟机"。
- 引申一(权限=AI 的手):"iPhone 无论如何它都不可能给你那个权限……你 AI 如果没有权限,它就不可能干事。""没有终端的话,等于说你没有办法通过打字跟手机交流,对 Agent 来说很难办。"
- 引申二(完美手机 Linux 思想实验):"如果一个完整的 Linux,它首先兼容安卓……还 可以跑虚拟机、跑 Docker,给了用户充足的权限。这个按理来讲是完美系统,怎么就没有了呢?"

### B2. 狗拿钱定理·完整版【自创】(篇004,与 A 区 024 呼应,B 区给出全定义)
- 民间表述:"当应该有的钱没有了的时候,这钱肯定是被狗拿走的。""我知道这是搞笑的,但是这很本质。"
- 学术表述(他本人与 AI 共同提炼并认可):"当财富发生损失的时候,存在一部分主体,已经从这套交易链条拿到了实实在在的收益,却完全不用为这次损失承担代价。这些主体,就是'狗'。"
- 等价命题:收益私有化、损失社会化(外部化)≈ 负外部性理论。
- 公理前提:"钱不会消失,钱只会转移。东西是会坏掉的,但是钱是不会消失。"
- 万能公式:"去银行存款和贷款的差额被谁拿走了?股票里高买低卖的差额被谁拿走了?赌场里钱被谁拿走了?保险的钱被谁拿走了?这简直就是万能公式。"
- 适用边界(他自己划的):正常消费不适用(那是"应该没有的钱没有了");保险场景的适用点是"你要求偿的时候保险公司不报给你"。
- 起源:恒大 2 万亿讨论("人生三万天,他一天得欠一个亿")。
- 中国古文对应:"天之道损有余而奉不足,人之道则不然,损不足以奉有余"——保险公司年年赚钱派股息,"刚好对应人之道"。

### E1. Docker Desktop bug 上报(篇140)——以 fengyuwang-com 身份在 docker/desktop-feedback 提交专业 issue
- Root cause:AF_UNIX socket 落在 NTFS + afd.sys 内核锁,unclean exit 后 0 字节 ReparsePoint 文件无法删除(error 1920)。
- 级联发现:"Cleaning one corrupted socket exposes the next"(dockerInference → engine.sock → userAnalyticsOtlpHttp.sock)。
- Workaround:重命名父目录(目录能改名而内容不能触碰)、EnableDockerAI:false、降级 4.69.0。
- Suggested fixes:socket 删除失败不应 fatal、可选服务故障不应拖垮引擎、提供 actionable 恢复动作而非只有"Reset to factory defaults"。
- 判定:系统性 debug 能力的公开证据,可直接做成博客《我给 Docker 报了一个级联 bug》。
