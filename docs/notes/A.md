### 1.4 四重过滤恐惧极点策略 ★★（054 提出，178 完整参数+代码）
- 完整参数（178 代码头注释）：
  1. 连续下跌 3 月（LOOKBACK_DAYS=63 交易日，收盘低于 63 日前）
  2. 单日跌 ≥3%（DROP_THRESHOLD）
  3. PE 绝对值 ≤15（PE_ABS_MAX）
  4. PE 历史百分位 ≤20%（5 年窗口 1260 日）
  - 出场：止盈 +8% / 止损 -3%（以信号日 low 计算）/ 120 日超时；手续费双边万6（TC=0.0003*2）
  - 股票池：15 只沪深蓝筹（茅台/工行/建行/招行/农行/中行/恒瑞/格力/美的/伊利/五粮液/中石化/中石油/长电/兴业）
  - 输出：逐笔明细 JSON + 子样本分层（PE≤10 vs 10-15；分位≤10% vs 10-20%）+ 分年度直方图
- 恐惧的原始定义（054）："连续下跌三五个月，然后突然有一天又下跌了 5% 以上，这个叫真的恐惧到达极点……2022 年的三四月份……20 年新冠疫情之后开盘那一天，那个叫恐惧。"
- 前提修正（054）："别人恐慌我贪婪，我的前提是你要买最好的股票……你买的就是 A 股里面的工商银行，这能重新测一遍吗？"
- 验证文化：论断编号制（verify-011-vix-panic-buy.py，"论断 #11: VIX>30 恐慌期买入跑赢平静期"，claim_supported 判定，3/4 持有期成立才算 SUPPORT）——审计式投资学。

## 3. 具体方法（可执行）
1. 四重过滤策略（见 1.4，参数齐全）
2. 论断验证制：每个投资断言编号 → Python 回测 → claim_supported YES/NO → results.json（054/178）
3. 复权四件套数据库（002）
4. 成本假设 0.1%/笔（002）+ 港股千一印花税敏感性（024：香港高频量化必死）
5. 自研指数替代官方指数（069 后续/086 附近："市盈率 20 倍以上我就已经打起精神了，30 倍以上我已经不研究了……如果我要自研指数的话……客观标准是很多的"）
6. 微信数据价值测算（012）："微信里面真加一个 AI 开关的话，腾讯市值增加 5000 亿没问题"——文字复刻性格、语音复刻声音、支付复刻消费。
7. 蚂蚁估值反推（065）：营收 30 亿美金 vs 3000 亿美金估值 → 估值必须解释得通。
8. CFD/期权期望收益审计（009）："我随便买一个 Put 或者卖一个 Put，我的期望收益是正数吗？"→ 雪球/covered call 全部按"横竖都是给金融机构赚走"框架审计；结论（009）："买 Call 卖 Call 买 Put 卖 Put 都不如直接持有正股……因为本质上还是跟人家赌。"
