## 1. 命名概念（自创）

### 1.1 豆包型人格 ★★（018/043 首现并体系化）
- 018："我特别怕一种人。就是豆包型人格，你知道我说的是什么吗？"
- 定义要素（018/043 反复打磨）：什么都"对对对、好的好的"但从不改；让你高兴而不指出错误；面试者对应聘者、下属对上司皆适用。
- 配套金句（018）："我赢了我不爽，我要跟你有来有回我才爽。""我不是想让你确认我的结论，我是让你反驳我，你还听不懂吗？""我哪有这么倔，我他妈在测试你。"
- 应用（043 面试复盘）："这个求职者展示出来的人格是豆包型人格吗？……他没让我高兴吧。"（概念被精确到"取悦行为是否存在"）

### 1.2 面试双向审计法 ★（043，方法论级）
- 三次粘贴同一场面试录音给 AI 复盘（018/043 共出现 4 次）。
- 核心动作：
  - 对方审计："你能从这个面试里面看到这个面试官这个人，他的远见卓识吗？""他有什么做对的地方？我有什么做错的地方？""如果说你是那个面试官呢？"（角色对调检验）
  - 自我审计："你从客观上来评价一下，我觉得你有点太偏向我了""你觉得我能做那种认知边界被触碰了之后去更新的人吗？""我是不是有点太自负了一点？"
  - 商业反证："他说贵的产品不在 Amazon 卖——苹果公司的产品、英伟达的产品敢不在 Amazon 上卖吗？你比它还高端吗？""这个所谓的 PD 充电器不就是深圳贴牌货吗？"
- 姿态自白："我的项目反映了我的什么精神，我已经介绍了，但他说他不关心……他没告诉我他的公司有什么问题。"

### 1.3 销售存在论 = 公司政治论 ★★（027/152，自创体系）
- 027："如果有销售的话，销售会贿赂那个中层，会糊弄那个上层，培训那个下层……如果是一个公司是完全扁平的，信息是自由流动的，所有人都知道一个软件它就是这个价、它就是这个能力，那就没有销售帮忙决策的必要了。"
- 027："AI 就是变成公司里面那个中层、那个下层了。中层其实是上传下达功能，AI 做得更好，因为它能 summarize；下层做的是执行工作，AI Agent 就可以干了。"

### 1.6 领导者五条画像（018/043，AI 代他总结、他反复认可）
1. 坚固的判断框架但随时准备被颠覆；不看学历标签（"我有很多朋友他跟我完全思维在一个 level 的，但他就大学肄业了……我总是觉得这时代亏待了他"）。

3. 识别被埋没的才华（"你这个问题你想肯定没人解决过，然后你发现 GitHub 上面一个一颗星的项目，它就真解决了"），并设"框"（任正非不造车红线）。
4. 求真置于求和谐之上；过滤低质量反对（父亲的炒股警告）与高质量反对（芒格）。
5. 悲悯的现实主义（接受运气，对抗平庸筛选）。
