# 全站检测清单（check_site.py 规划稿）

2026-09-06 落盘。约 16000 条原子检查，分四层：静态脚本 / 渲染测试 / 线上验证 / 人工。

## 一、逐页 head（78 页 × 8 项 = 624 条）

1. title 非空且全站不重复
2. title 长度 10-60 字
3. meta description 存在
4. description 长度 50-160 字
5. canonical 存在且指向自己
6. hreflang 自指存在
7. og:title / og:image 社交标签
8. html lang 属性正确（en 页 lang=en）

## 二、逐页内容（78 页 × 6 项 = 468 条）

9. 页面字符数不为 0，有可见正文
10. 渲染内容比源文件缩水超一半报警（内容被吞伞检查）
11. 无未渲染的模板符号 {{ }}
12. 无 Hugo 调试注释
13. UTF-8 无乱码
14. 恰好一个 h1，标题层级不断层

## 三、逐页结构（78 页 × 10 项 = 780 条）

15. viewport 存在
16. favicon 引用存在
17. CSS/JS/图片引用全存在
18. 页面内链接全部 200
19. 锚点 #id 在目标页真实存在
20. 图片有 alt 属性
21. 外链一律 https
22. 返回博客/返回首页按钮存在
23. 页脚联系方式三语一致（邮箱、GitHub、LinkedIn）
24. 导航项三语数量、指向一致

## 四、三语对等（26 页 × 5 项 = 130 条）

25. zh-cn 有的页面 en/zh-hk 都有
26. 同页三语标题语义对应
27. 语言切换器每页都能找到另外两语
28. 三语正文长度比例 0.6-1.6（翻译丢失信号）
29. 同页三语 tags 一一对应

## 五、逐篇文章（94 篇 × 3 语 × 15 项 = 4230 条）

30. frontmatter 八字段齐全（title/date/description/slug/tags/draft/translationKey）
31. date 合法且不超今天
32. tags 1-5 个
33. 痕迹词零命中（元宝/它说/我问它/这场对话/跟AI聊）
34. 新文直角引号禁令（旧手写稿豁免名单）
35. 汉字数下限（en 除外）
36. description 长度下限（金句式一句话风格豁免，阈值 10 字）
37. 代码围栏闭合（``` 偶数）
38. 裸 HTML 无围栏检测（Hugo 静默丢弃，简历事故）
39. zh-hk 简体泄漏（opencc 可转而未转，排除上下文相关字 佣/里/干/游）
40. zh-hk 港台用词表（信息→資訊、软件→軟體、视频→影片）
41. zh-cn 繁体泄漏
42. en 正文 CJK 残留（排除代码块内简历模板）
43. translationKey 三语成组（95 组）
44. 文内链接 200
45. 渲染页存在、有日期、有 tags、返回按钮指向正确列表页

## 六、部署一致性（P0 漂移检测）

46. 源篇数 = 根目录副本篇数（按 slug 比对）
47. 副本内容 hash = 源渲染预期（过期检测）
48. RSS 条数 = 实际发布篇数
49. _site 已清理，无残留
50. draft 文章未出现在副本（deepseek-v4）

## 七、SEO 全站（约 300 条）

51. sitemap 逐条 URL 对应文件存在
52. sitemap 无重复 URL
53. robots.txt 存在且指向 sitemap
54. 404 页存在
55. _redirects 每条目标存在
56. 全站无重复 canonical

## 八、配置与安全（约 30 条）

57. _headers 覆盖三语 blog 路径
58. llms.txt 引用全存在
59. CF token 占位符提醒（WARN 不挡发布）
60. 版本号一致：VERSION = 页面 cache-buster = navbar.js 参数
61. 无 .md 源文件、.git、server.py、日志等被部署到线上
62. 无引用了但不存在的资源；无存在但没人引用的死资源
63. 图片单张不超 500KB

## 九、排版与暗色模式（脚本静态层，新增）

64. 每个浅色规则（#fff 等）都有 body[data-theme="dark"] 覆盖
65. 内联 style 写死颜色但无暗色覆盖的报警
66. 正文容器有 max-width
67. img 有 max-width:100%（手机溢出）
68. @media (max-width) 响应式规则存在于每个带样式页面

## 十、渲染级测试（脚本做不到，用浏览器工具，部署前抽查）

69. 真实渲染逐页截图：列表页、文章页、首页、404（每个模板类型）
70. 暗色模式切换后无对比度问题、无白色残留块
71. 交互可用：搜索框、排序、标签筛选、返回顶部、移动端菜单
72. 手机宽度（375px）下无横向溢出、无文字重叠

## 十一、线上验证（部署后另跑）

73. WebFetch 线上确认新文章出现、HTTP 200
74. 线上文章数 = 本地（验证 CF Pages 已拉取）
75. 线上 hreflang / RSS 头正确

## 十二、永远靠人读

76. 观点质量、逻辑自洽、案例真实
77. 同题重复粗筛（脚本只能做标题相似度提醒）
78. 素材围墙：私人上下文泄露（脚本只做敏感词粗筛）
