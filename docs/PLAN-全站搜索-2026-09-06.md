# 规划：博客全站搜索（正文+标题+摘要+标签+标签归档）

日期：2026-09-06　状态：待执行

## 用户需求
1. 搜索覆盖**全部 94 篇文章**（不是当前页 12 篇）。
2. 搜索字段：**正文全文（重点）+ 标题 + 摘要 + 标签**。
3. 结果两部分：
   - 匹配的**标签**（点击跳转标签归档页）；
   - 匹配的**文章列表**（点击进文章），并展示正文命中的片段，体现"文本写了什么"。

## 技术方案（纯静态，零运行时）
- Hugo 构建时生成 JSON 索引：`hugo.toml` 的 `[outputs] section = ["HTML","RSS","JSON"]`；
  新建 `hugo/layouts/blog/list.json`，输出每篇文章：
  `{ url, title, description, tags[], date, content(plainify 正文) }`。
  产物为 `/{lang}/blog/index.json`（约 94 篇 × 正文，每语言几百 KB，可接受；Cloudflare Pages gzip 后更小）。
- `hugo/layouts/blog/list.html` 重写搜索 JS：
  - 页面加载时惰性 fetch 一次 `index.json`（首次输入才拉取）；
  - 输入时在索引中匹配 title/description/tags/content（小写 indexOf）；
  - 有关键词时：隐藏原生分页 grid + 分页条，改为渲染动态结果区：
    1. 顶部一行「相关标签」：匹配的标签 pill，链到 /{lang}/tags/{slug}/；
    2. 下方文章卡片：标题 + 摘要 + **正文命中片段**（命中点前后各取 ~80 字符，关键词高亮）+ 标签 chips；按日期排序；
    3. 计数「N 篇文章 · M 个标签」；无结果显示「无结果」；
  - 清空关键词：恢复原生 grid + 分页。
- i18n：en / zh-hk / zh-cn 三语文案；暗色模式沿用 .blog-card 既有样式。
- deploy.sh 不用改（blog 目录整体拷贝，index.json 自动带上）。
