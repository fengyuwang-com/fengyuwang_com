## 二、发现清单(按严重度)

### F-1 [P0] 线上博客落后 53 篇 × 三语
- 证据:Hugo 源 95 篇,仓库根部署副本只有 42 篇;线上列表页 4 页且无"收费站/飞狗/泡泡玛特/供应商锁定"等新题;根 RSS 41 条 vs 新构建 94 条。
- 原因:hugo/deploy.sh(构建→把 _site/{lang}/blog 拷到仓库根)在最近几批文章生产后没有再执行。
- 修复:跑 `hugo --buildFuture` + `deploy.sh`,根副本变 95 篇,commit + push dev。**不改动任何文案**,属发布动作。master 是否同步由你决定(master 动作必经你授权)。
- 附带收益:根 RSS 从 41 → 94 条,列表分页从 4 页变 8 页。

### F-2 [P1] 61 篇旧文三语 translationKey / slug 错位 → 语言切换与 hreflang 失效
- 证据:zh-hk 旧文 frontmatter 的 slug/translationKey 是繁体(aihtml简歷、pdca-循環…),en 有 3 篇自创中英混拼 slug(几内亚比绍完整国情与power-behind-the-throne实现路径 等),与目录名不一致。61 组 translationKey 三语不齐。
- 后果:这些文章页 IsTranslated=false,导航语言切换器拿不到另外两语链接;baseof 的 hreflang 兜底用"替换语言前缀"生成替代链接,对 zh-hk/en 会指向不存在的 URL。
- 修复(需批复):机械统一 translationKey = zh-cn 目录名,slug 字段与目录名对齐。
  批复理由:让读者在任一语言版本一键切到另两语——向别人展示你的思想时不被语言卡住;SEO 三语互链也全部修正。

### F-3 [P1] 《aihtml简历》(三语)简历 HTML 被静默丢弃
- 证据:正文中代码围栏反引号丢失(只剩一行孤立的"html"),其后整块 `<!DOCTYPE html>…` 被 Hugo 当 Raw HTML 省略(构建有 WARN)。渲染出的正文 2795 字符、不含"个人简历"——线上这篇文章没有简历本体。
- 修复(需批复):补回 ``` 围栏,让简历以代码形式完整可见。
  批复理由:这篇文章的全部价值就是那份简历,现在读者看到的是一篇被砍掉核心的残文。

### F-4 [P2] zh-hk 简繁质量两级分化
